# Ресурси та курси

Добірка безкоштовних якісних ресурсів, які корисно використовувати як опору під час
підготовки занять, а також давати студентам як додаткові матеріали чи референси.
Позначки: **(UA)** / **(EN)** — мова ресурсу. Де є вибір — україномовні джерела йдуть першими.

## Загальні платформи та мотивація (українською)

- [Prometheus](https://prometheus.org.ua) **(UA)** — український майданчик безкоштовних масових онлайн-курсів (частина — дубльовані курси Duke/Harvard за підтримки Посольства США в Україні); варто періодично перевіряти актуальний каталог.
- [ITVDN — «Безкоштовно для України»](https://itvdn.com/ua/landing/free-for-ukraine) **(UA)** — 30 днів безкоштовного доступу до 300+ відеокурсів (Java, алгоритми, API/Postman, frontend та ін.) для громадян України; потрібна коротка заявка на верифікацію (1-2 дні).
- [itProger](https://itproger.com/ua) **(UA)** — україномовна платформа з безкоштовними відеоуроками з програмування (Java, Python, PHP та інші).
- [EdEra](https://www.ed-era.com) **(UA)** — українська освітня платформа з безкоштовними курсами, частина стосується IT/цифрової грамотності.
- [Дія.Освіта](https://osvita.diia.gov.ua) **(UA)** — державна платформа безкоштовних освітніх серіалів, є базові IT/цифрові курси.
- YouTube-канали українських IT-шкіл **(UA)**: Mate academy, GoIT, Hillel IT School — безкоштовні вебінари та вступні лекції з програмування, добре підійдуть як мотиваційні відео саме для заняття 1 (вступ у професію).
- [roadmap.sh](https://roadmap.sh) **(EN)** — візуальні кар'єрні роадмапи (Backend, Frontend, Java, SQL тощо), теж добре показати на вступному занятті "куди ви рухаєтесь".

## Java основи

- [Prometheus — Основи програмування на Java](https://prometheus.org.ua/prometheus-free/fundamentals-of-java-programming/) **(UA)** — повністю безкоштовний 7-тижневий курс: основи Java + ООП (класи, наслідування, інтерфейси, винятки).
- [Prometheus — Програмування на Java: Програмне забезпечення](https://prometheus.org.ua/prometheus-free/java-programming-software-development/) **(UA)** — курс від Duke University, безкоштовний.
- [W3Schools українською — Java](https://w3schoolsua.github.io/java/index.html) **(UA)** — перекладений довідник із прикладами, зручний як шпаргалка для студентів.
- [itProger — курс Java для початківців](https://itproger.com/ua/course/java) **(UA)** — безкоштовні відеоуроки з нуля.
- [MOOC.fi — Java Programming I & II](https://java-programming.mooc.fi) **(EN)** — Університет Хельсінкі, повністю безкоштовний, дуже практичний, з автоперевіркою завдань. Найкраща база для структури занять блоку 1-2.
- [Oracle Java Tutorials](https://docs.oracle.com/javase/tutorial/) **(EN)** — офіційна документація/туторіали від творця мови, надійне джерело для перевірки термінології та деталей синтаксису.
- [CS50x (Harvard, edX)](https://cs50.harvard.edu/x/) **(EN)** — безкоштовний для проходження (сертифікат платний), сильна подача основ програмування та алгоритмічного мислення, гарні відеолекції для натхнення.

## ООП

- [W3Schools українською — Вступ до ООП](https://w3schoolsua.github.io/hyperskill/oop-intro.html) **(UA)** — коротке пояснення принципів ООП простими словами.
- [W3Schools українською — Java ООП](https://w3schoolsua.github.io/java/java_oop.html) **(UA)** — класи, наслідування, інтерфейси на прикладах Java.
- [MOOC.fi Java Programming II](https://java-programming.mooc.fi/part-7) **(EN)** — розділи саме про ООП (класи, наслідування, інтерфейси) з практичними вправами.
- [Baeldung — OOP in Java](https://www.baeldung.com/java-oop) **(EN)** — стислі, конкретні статті по кожній темі ООП, зручно як референс під час підготовки.

## Алгоритми та структури даних

- [W3Schools українською — DSA](https://w3schoolsua.github.io/dsa/index.html) **(UA)** — стислий безкоштовний довідник по структурах даних і алгоритмах (сортування, пошук, складність).
- [VisuAlgo](https://visualgo.net) **(EN)** — візуалізація алгоритмів сортування/пошуку/структур даних в анімації, чудово для демонстрації на екрані під час пари.
- [freeCodeCamp — JavaScript Algorithms and Data Structures](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/) **(EN)** — концепції переносяться на будь-яку мову, повністю безкоштовно з практичними завданнями.
- [Codewars](https://www.codewars.com) **(EN)** — гейміфіковані задачі (kata) різного рівня складності, добре як бонусні/самостійні завдання між заняттями.
- [Big-O Cheat Sheet](https://www.bigocheatsheet.com) **(EN)** — компактна шпаргалка складності алгоритмів.

## Git та GitHub

- [Git How To](https://githowto.com/uk) **(UA)** — інтерактивний тур по основах Git прямо в браузері.
- [W3Schools українською — Git](https://w3schoolsua.github.io/git/index.html) **(UA)** — покроковий довідник по командах Git та GitHub.
- [Pro Git book](https://git-scm.com/book/uk/v2) **(UA, офіційний переклад)** — повна безкоштовна книга по Git українською.
- [Learn Git Branching](https://learngitbranching.js.org) **(EN, є вибір мови в інтерфейсі)** — інтерактивна візуальна пісочниця для гілок/merge, чудово для практики на занятті.
- [GitHub Skills](https://skills.github.com) **(EN)** — офіційні короткі інтерактивні курси від GitHub (Pull Requests, Merge conflicts, тощо).

## Бази даних / SQL

- [Prometheus — Вступ до баз даних та мови SQL](https://prometheus.org.ua/prometheus-free/introduction-to-databases-and-sql/) **(UA)** — курс Harvard University, безкоштовний, ~11.5 год відео: SQL, реляційна модель, нормалізація, JOIN, індекси, транзакції, фінальний проєкт.
- [W3Schools українською — SQL](https://w3schoolsua.github.io/sql/index.html) **(UA)** — перекладений довідник з прикладами запитів.
- [SQLZoo](https://sqlzoo.net) **(EN)** — інтерактивні вправи прямо в браузері, від простого SELECT до JOIN.
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/) **(EN)** — послідовний безкоштовний курс із теорією і практикою.
- [SQL Murder Mystery](https://mystery.knightlab.com) **(EN)** — гра-розслідування на SQL-запитах, чудовий інтерактив для заняття з чекпоінтом.
- [PostgreSQL Tutorial (офіційний)](https://www.postgresql.org/docs/current/tutorial.html) **(EN)** — офіційна документація для перевірки деталей синтаксису.

## HTTP / API / Веб основи

- [ITVDN — стаття про REST API](https://itvdn.com/ua/blog/article/rest-api-18) **(UA)** — коротке пояснення що таке REST API простими словами, безкоштовно.
- [MDN Web Docs — HTTP](https://developer.mozilla.org/uk/docs/Web/HTTP) **(частина сторінок перекладена UA, основне EN)** — найавторитетніше джерело по HTTP, HTML, CSS.
- [Postman Learning Center](https://learning.postman.com) **(EN)** — офіційні гайди по роботі з Postman і тестуванню API.
- [http.cat](https://http.cat) **(без слів)** — HTTP статус-коди через фото котів, гарний легкий інтерактив для заняття про статус-коди.

## HTML/CSS основи

- [Prometheus — Основи програмування з HTML, CSS та JavaScript](https://prometheus.org.ua/prometheus-free/programming-fundamentals-html-css-javascript/) **(UA)** — курс Duke University, безкоштовний.
- [W3Schools українською — HTML](https://w3schoolsua.github.io/html/index.html) / [CSS](https://w3schoolsua.github.io/css/index.html) **(UA)** — перекладені довідники з прикладами.
- [MDN — Learn HTML](https://developer.mozilla.org/en-US/docs/Learn/HTML) / [Learn CSS](https://developer.mozilla.org/en-US/docs/Learn/CSS) **(EN, частина сторінок є UA)** — структуровані безкоштовні уроки від Mozilla.
- [freeCodeCamp — Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/) **(EN)** — повний безкоштовний курс із сертифікатом, багато практики.

## Як використовувати цей список

- **Для підготовки занять:** офіційна документація (Oracle, MDN, PostgreSQL) — звірити точність термінів і прикладів; MOOC.fi/freeCodeCamp/Prometheus — як структурний орієнтир для послідовності подачі теми.
- **Для студентів як довідник рідною мовою:** W3Schools українською (Java, ООП, DSA, Git, SQL, HTML, CSS) — давати як основний "довідник" паралельно з заняттями.
- **Для студентів як інтерактив:** VisuAlgo, Learn Git Branching, Git How To, SQLZoo, SQL Murder Mystery, Codewars, http.cat — в секції "Додаткові матеріали" відповідного заняття.
- **Для глибшого проходження курсом:** Prometheus (Java, SQL, HTML/CSS/JS) та ITVDN «Безкоштовно для України» — повноцінні структуровані курси з сертифікатом, добре запропонувати як домашнє поглиблення для зацікавлених.
- **Для мотивації:** роздивитись на занятті 1 разом зі студентами roadmap.sh та коротке відео однієї з українських IT-шкіл.
