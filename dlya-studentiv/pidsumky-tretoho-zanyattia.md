## 📍 Що розглянули

- [Теорію](https://github.com/misha-lavrov/Programming-basics-course/blob/main/semester-1/010-osnovy-java/030-zminni-typy-danyh.md#2-%D0%BA%D0%BE%D1%80%D0%BE%D1%82%D0%BA%D0%B0-%D1%82%D0%B5%D0%BE%D1%80%D1%96%D1%8F-1520-%D1%85%D0%B2): що таке змінна, основні типи даних (`int`, `double`, `boolean`, `char`, `String`), як оголошувати змінні та читати ввід через `Scanner`.
- Примітивних типів даних у Java всього **8**: `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`. Прочитати про них і про межі значень кожного можна тут: [W3Schools українською — типи даних](https://w3schoolsua.github.io/java/java_data_types.html) (UA) або в [Oracle Java Tutorials — Primitive Data Types](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html) (EN).
- Тип `char` підтримує близько **65 тисяч символів** (від 0 до 65 535) відповідно до стандарту **Юнікод (Unicode)**: [Юнікод у Вікіпедії](https://uk.wikipedia.org/wiki/%D0%AE%D0%BD%D1%96%D0%BA%D0%BE%D0%B4) (UA).
- Кілька прикладів: [Greeting.java](https://github.com/misha-lavrov/Programming-basics-course/blob/main/semester-1/010-osnovy-java/src/030-zminni-typy-danyh/Greeting.java) і [SimpleCalculator.java](https://github.com/misha-lavrov/Programming-basics-course/blob/main/semester-1/010-osnovy-java/src/030-zminni-typy-danyh/SimpleCalculator.java).
