# Ресурси та курси

Добірка безкоштовних якісних ресурсів, які корисно використовувати як опору під час
підготовки занять, а також давати студентам як додаткові матеріали чи референси.
Позначки: **(UA)** / **(EN)** — мова ресурсу. Де є вибір — україномовні джерела йдуть першими.

## Загальні платформи та мотивація (українською)

- [Prometheus](https://prometheus.org.ua) **(UA)** — український майданчик безкоштовних масових онлайн-курсів (частина — дубльовані курси Duke/Harvard за підтримки Посольства США в Україні); варто періодично перевіряти актуальний каталог.
- [ITVDN — «Безкоштовно для України»](https://itvdn.com/ua/landing/free-for-ukraine) **(UA)** — 30 днів безкоштовного доступу до 300+ відеокурсів (Java, алгоритми, API/Postman, frontend та ін.) для громадян України; потрібна коротка заявка на верифікацію (1-2 дні).
- [itProger](https://itproger.com/ua) **(UA)** — україномовна платформа з безкоштовними відеоуроками з програмування (Java, Python, PHP та інші).
- [EdEra](https://www.ed-era.com) **(UA)** — українська освітня платформа з безкоштовними курсами, частина стосується IT/цифрової грамотності.
- [Дія.Освіта](https://osvita.diia.gov.ua) **(UA)** — державна платформа безкоштовних освітніх серіалів, є базові IT/цифрові курси.
- YouTube-канали українських IT-шкіл **(UA)**: Mate academy, GoIT, Hillel IT School — безкоштовні вебінари та вступні лекції з програмування, добре підійдуть як мотиваційні відео саме для заняття 1 (вступ у професію).
- [roadmap.sh](https://roadmap.sh) **(EN)** — візуальні кар'єрні роадмапи (Backend, Frontend, Java, SQL тощо), теж добре показати на вступному занятті "куди ви рухаєтесь".

## Java основи

- [Prometheus — Основи програмування на Java](https://prometheus.org.ua/prometheus-free/fundamentals-of-java-programming/) **(UA)** — повністю безкоштовний 7-тижневий курс: основи Java + ООП (класи, наслідування, інтерфейси, винятки).
- [Prometheus — Програмування на Java: Програмне забезпечення](https://prometheus.org.ua/prometheus-free/java-programming-software-development/) **(UA)** — курс від Duke University, безкоштовний.
- [W3Schools українською — Java](https://w3schoolsua.github.io/java/index.html) **(UA)** — перекладений довідник із прикладами, зручний як шпаргалка для студентів.
- [itProger — курс Java для початківців](https://itproger.com/ua/course/java) **(UA)** — безкоштовні відеоуроки з нуля.
- [MOOC.fi — Java Programming I & II](https://java-programming.mooc.fi) **(EN)** — Університет Хельсінкі, повністю безкоштовний, дуже практичний, з автоперевіркою завдань. Найкраща база для структури занять блоку 1-2.
- [Oracle Java Tutorials](https://docs.oracle.com/javase/tutorial/) **(EN)** — офіційна документація/туторіали від творця мови, надійне джерело для перевірки термінології та деталей синтаксису.
- [CS50x (Harvard, edX)](https://cs50.harvard.edu/x/) **(EN)** — безкоштовний для проходження (сертифікат платний), сильна подача основ програмування та алгоритмічного мислення, гарні відеолекції для натхнення.

- [W3Schools українською — Java ООП](https://w3schoolsua.github.io/java/java_oop.html) **(UA)** — класи, наслідування, інтерфейси на прикладах Java.

- [Baeldung — OOP in Java](https://www.baeldung.com/java-oop) **(EN)** — стислі, конкретні статті по кожній темі ООП, зручно як референс під час підготовки.

## Практика з автоматичною перевіркою (задачі й тренажери)

Усе нижче безкоштовне й перевіряє відповідь автоматично — студент одразу бачить, правильно чи ні.
Українською — першими.

### Українською

- [Algotester](https://algotester.com/uk) **(UA)** — українська платформа алгоритмічних задач: умови українською, автоперевірка, можна розв'язувати на Java. Є великий архів задач, а також змагання для початківців (наприклад, Algotester Beginners Contest — разові події, варто стежити за анонсами на сайті).
- [Eolymp](https://eolymp.com/uk/problems) **(UA/EN)** — понад 9 000 задач, інтерфейс і умови українською; у фільтрі задач є позначки «Дуже легка» та «Для початківців» — з них варто починати. Підтримує Java.

> Обидві платформи працюють за форматом «олімпіадних» задач: програма читає вхідні дані через `Scanner` (знайомий з блоку 1) і виводить відповідь через `System.out` — це добре тренує саме той ввід/вивід, який вивчали на гуртку. Перші задачі добре підходять на додаткову практику після блоків 1–3.

### Java (англійською)

- [CodingBat — Java](https://codingbat.com/java) **(EN)** — найлегший старт: дрібні задачки на рядки, масиви, цикли й логіку; код пишеться і перевіряється прямо в браузері, результат одразу. Ідеально для блоку 1 (заняття 030–090) як «розминка» між заняттями.
- [Exercism — Java track](https://exercism.org/tracks/java) **(EN)** — 158 вправ, згрупованих за 26 темами Java, повністю безкоштовно. Вправи побудовані на тестах (студент пише код, поки всі тести не пройдуть — це ще й знайомство з тим, як працює тестування в реальних проєктах), після розв'язку можна отримати відгук від волонтерів-менторів. Добре підходить для блоків 2–3.
- [MOOC.fi — Java Programming](https://java-programming.mooc.fi) **(EN)** — вже в списку вище; окремо нагадую, що це один з найкращих варіантів саме для практики: кожна тема закінчується вправами з автоперевіркою.
- [Codewars](https://www.codewars.com) **(EN)** — вже в списку вище; задачі (kata) за рівнями складності з рангами, добре для самостійної практики наприкінці блоків 1–3.
- [HackerRank — Java](https://www.hackerrank.com/domains/java) **(EN)** — задачі за темами й рівнем складності, в стилі технічних співбесід; для користування, імовірно, потрібен безкоштовний акаунт. Доречно ближче до кінця блоку 3.
- [LeetCode](https://leetcode.com/problemset/) **(EN)** — класика для підготовки до співбесід; для початку достатньо фільтра «Easy». Частина задач платна, але безкоштовних більш ніж достатньо.

### SQL (бази даних, блок 5)

- [PostgreSQL Exercises (pgexercises.com)](https://pgexercises.com) **(EN)** — вправи саме на PostgreSQL (як і в нашому курсі) на одній зрозумілій навчальній базі даних, від простих `SELECT` до `JOIN` та агрегації. Безкоштовно. Найкращий варіант для практики після занять 040–070.
- [SQLBolt](https://sqlbolt.com) **(EN)** — інтерактивні уроки з вправами прямо в браузері, кожен урок закінчується практикою з миттєвою перевіркою. Підходить для самого початку блоку 5 (заняття 040–050).
- [HackerRank — SQL](https://www.hackerrank.com/domains/sql) **(EN)** — задачі від базових (`Basic Select`) до `JOIN` та агрегації, з автоперевіркою.
- [SQLZoo](https://sqlzoo.net) та [SQL Murder Mystery](https://mystery.knightlab.com) — вже в списку вище, теж з автоматичною перевіркою.

### Git (блок 4)

- [Learn Git Branching](https://learngitbranching.js.org) — вже в списку вище; рівні з перевіркою результату, саме для тренування гілок і злиття.
- [Oh My Git!](https://ohmygit.org) **(EN)** — безкоштовна open-source гра про Git, яка наочно показує структуру репозиторію під час виконання команд. Потрібно завантажити (є версії для Windows, macOS, Linux), у браузері не працює.

### HTML/CSS (блок 6)

- [Flexbox Froggy](https://flexboxfroggy.com) **(UA/EN)** — гра на CSS flexbox: студент пише CSS, гра сама перевіряє результат. Має **український інтерфейс**. У тих самих авторів є схожа гра [Grid Garden](https://cssgridgarden.com) для CSS Grid (на подальше).
- [CSS Diner](https://flukeout.github.io) **(EN)** — гра на CSS-селектори з миттєвою перевіркою на кожному рівні.
- [freeCodeCamp — Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/) — вже в списку вище; кожен крок має автоматичну перевірку.

### Як вплести практику в гурток

- **Блок 1 (основи Java):** CodingBat між заняттями як «розминка» на 10–15 хв; наприкінці блоку — кілька «дуже легких» задач на Eolymp чи Algotester.
- **Блоки 2–3 (ООП, алгоритми):** Exercism (вправи на тестах) і Codewars (рівень 8 kyu → 7 kyu).
- **Блок 4 (Git):** Learn Git Branching на занятті, Oh My Git! — вдома для охочих.
- **Блок 5 (SQL):** SQLBolt на старті, PG Exercises — як основна практика після занять 040–070.
- **Блок 6 (веб):** Flexbox Froggy і CSS Diner — на занятті про CSS або як необов'язкове домашнє завдання.
- Щоб підтримувати інтерес: можна завести в групі невеликий неофіційний «рейтинг» (скільки задач розв'язано за тиждень на Codewars/Exercism/Eolymp) — гейміфікація без оцінок.

## Як використовувати цей список

- **Для підготовки занять:** офіційна документація (Oracle, MDN, PostgreSQL) — звірити точність термінів і прикладів; MOOC.fi/freeCodeCamp/Prometheus — як структурний орієнтир для послідовності подачі теми.
- **Для студентів як довідник рідною мовою:** W3Schools українською (Java, ООП, DSA, Git, SQL, HTML, CSS) — давати як основний "довідник" паралельно з заняттями.
- **Для студентів як інтерактив:** VisuAlgo, Learn Git Branching, Git How To, SQLZoo, SQL Murder Mystery, Codewars, http.cat — в секції "Додаткові матеріали" відповідного заняття.
- **Для глибшого проходження курсом:** Prometheus (Java, SQL, HTML/CSS/JS) та ITVDN «Безкоштовно для України» — повноцінні структуровані курси з сертифікатом, добре запропонувати як домашнє поглиблення для зацікавлених.
- **Для мотивації:** роздивитись на занятті 1 разом зі студентами roadmap.sh та коротке відео однієї з українських IT-шкіл.
