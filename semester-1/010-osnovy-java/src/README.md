# Приклади коду до занять блоку 1

Кожна підпапка тут відповідає одному файлу заняття (та сама назва, без розширення `.md`)
і містить готові, робочі `.java`-файли, на які заняття посилається.

## Як запустити приклад

**Варіант A — в IntelliJ IDEA (рекомендовано для занять):**
1. Відкрити файл у IntelliJ IDEA (через File → Open, обрати сам `.java`-файл або папку `src` як проєкт).
2. Клацнути на зелений трикутник ▶ ліворуч від рядка `public static void main`.
3. Результат з'явиться в панелі "Run" внизу.

**Варіант B — через термінал (Java 11+, без окремої компіляції):**
```
java -Dfile.encoding=UTF-8 ІмяФайлу.java
```
Наприклад: `java -Dfile.encoding=UTF-8 HelloWorld.java`

**Варіант C — через термінал (класичний спосіб, працює завжди):**
```
javac -encoding UTF-8 ІмяФайлу.java
java -Dfile.encoding=UTF-8 ІмяФайлу
```
(перша команда компілює `.java` → `.class`, друга — запускає)

## Відома пастка: кирилиця і Windows-консоль

На Windows з українською/російською локаллю є дві типові проблеми з кирилицею, і обидві
перевірені на практиці при підготовці цих прикладів:

1. **Компіляція.** `javac` без прапорця `-encoding UTF-8` може видати помилку на кшталт
   `unmappable character ... for encoding windows-1251` — компілятор за замовчуванням
   читає файл не в UTF-8, а в кодуванні консолі. Файли в цьому репозиторії — в UTF-8,
   тому при компіляції через `javac` **завжди додавайте `-encoding UTF-8`**.
2. **Запуск.** Навіть якщо компіляція пройшла, український текст у виводі програми може
   показуватись "кракозябрами" (`????` замість букв). Рішення — запускати з прапорцем
   `-Dfile.encoding=UTF-8`, як у Варіантах B і C вище.

У IntelliJ IDEA (Варіант A) обидві проблеми, як правило, не виникають — саме тому це
рекомендований спосіб для занять.

## Примітка про іменування

Ім'я файлу завжди збігається з іменем публічного класу всередині (це правило Java,
не наша примха). Коментарі всередині файлів — українською, для пояснення; імена
змінних і класів — англійською, як прийнято в індустрії.
