# Оператори (operators)

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/040-operatory.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Арифметичні, порівняння, логічні, пріоритет операцій.

## Мета заняття
- Знати арифметичні оператори (`+ - * / %`) і особливості цілочисельного ділення
- Знати оператори порівняння (`== != > < >= <=`) і логічні (`&& || !`)
- Розуміти базовий пріоритет операцій

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Написати на дошці велике питання: **«Скільки буде `17 / 5` в Java?»**. Дати групі проголосувати підняттям рук між варіантами `3`, `3.4`, `2`. Потім запустити [`EvenOrOdd.java`](src/040-operatory/EvenOrOdd.java) наживо і по ходу пояснення розкрити правильну відповідь: `3`, бо ділення двох `int` в Java завжди дає `int` — дробова частина просто відкидається, без округлення.

### 2. Коротка теорія (15–20 хв)
**Арифметичні оператори:** `+` (додавання), `-` (віднімання), `*` (множення), `/` (ділення), `%` (залишок від ділення).

**Цілочисельне vs дробове ділення.** Якщо обидва операнди — `int`, результат `/` теж буде `int`, і дробова частина відкидається: `17 / 5` дає `3`, а не `3.4`. Щоб отримати точний дробовий результат, хоча б один з операндів має бути `double`:
```java
int a = 17, b = 5;
System.out.println(a / b);         // 3 (int-ділення)
System.out.println((double) a / b); // 3.4 (приведення до double)
```

**Оператор `%` (залишок від ділення)** повертає, що лишається після цілочисельного ділення. Найпоширеніше практичне застосування — перевірка парності: `number % 2 == 0` означає «число парне».

**Оператори порівняння:** `==` (дорівнює), `!=` (не дорівнює), `>`, `<`, `>=`, `<=`. Кожен з них повертає `boolean` (`true`/`false`).

**Логічні оператори:** `&&` (І — обидві умови мають бути `true`), `||` (АБО — достатньо однієї `true`), `!` (заперечення, обертає `true` на `false` і навпаки).

**Пріоритет операцій.** Діє звичне зі школи правило: спочатку множення/ділення, потім додавання/віднімання; дужки `()` завжди виконуються першими і дозволяють явно керувати порядком, коли є сумніви.

### 3. Демонстрація / live-coding (15–20 хв)
Показати [`FullCalculator.java`](src/040-operatory/FullCalculator.java) — калькулятор з усіма чотирма діями і залишком, з явним прикладом приведення до `double` для точного ділення.

### 4. Керована практика (20–30 хв)
Відкрити [`PredictTheOutput.java`](src/040-operatory/PredictTheOutput.java) — вправа «передбач результат». Перед запуском кожного окремого рядка запитувати групу, яким буде виведення, записувати здогадки на дошці, потім запускати і звіряти. Ця вправа охоплює одразу цілочисельне/дробове ділення, залишок, `&&`/`||`/`!` і пріоритет операцій.

### 5. Самостійна практика / челендж (20–30 хв)
Написати [`LeapYear.java`](src/040-operatory/LeapYear.java) — перевірку, чи є введений рік високосним. Правило (варто написати на дошці до того, як студенти почнуть писати код): рік ділиться на 4, **АЛЕ** якщо ділиться на 100 — то НЕ високосний, **АЛЕ** якщо ще й ділиться на 400 — то знову високосний. Це хороший челендж саме на комбінування `%`, порівнянь і логічних операторів в одному виразі.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити типові помилки: плутанина `=` (присвоєння) і `==` (порівняння) — це різні оператори з абсолютно різним призначенням; несподіванки цілочисельного ділення, які щойно розібрали на хуку.
