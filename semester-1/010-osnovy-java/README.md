# Блок 1. Старт і основи програмування

Файли пронумеровані з кроком 10 (010–100) — це залишає місце, щоб вставити нове заняття
між існуючими (наприклад `015-...`), не перейменовуючи решту файлів блоку.

## Заняття

- [010] [Вступ у професію. Хто такий розробник](010-vstup-u-profesiyu.md) — Мотивація: кар'єрні шляхи, зарплати, реальні історії, демо «що ви зможете створити за рік». Живе демо міні-програми на очах.
- [020] [Встановлення інструментів. Перша програма](020-instrumenty-persha-prohrama.md) — JDK, IntelliJ IDEA, як компілюється і виконується код, Hello World.
- [030] [Змінні та типи даних (variables, data types)](030-zminni-typy-danyh.md) — Примітивні типи, оголошення змінних, введення/виведення через Scanner.
- [040] [Оператори (operators)](040-operatory.md) — Арифметичні, порівняння, логічні, пріоритет операцій.
- [050] [Умовні конструкції](050-umovni-konstruktsii.md) — if / else / else if, switch.
- [060] [Цикли (loops)](060-tsykly.md) — for, while, do-while.
- [070] [Практика: задачі на умови та цикли](070-praktyka-umovy-tsykly.md) — Розв'язання невеликих задач (FizzBuzz-подібні), закріплення.
- [080] [Масиви (arrays)](080-masyvy.md) — Одновимірні масиви: створення, обхід, базові операції.
- [090] [Рядки (strings)](090-riadky.md) — Клас String, основні методи роботи з текстом.
- [100] [Практичний чекпоінт №1](100-praktychnyi-chekpoint-1.md) — Міні-програма (наприклад текстова гра типу «вгадай число» або калькулятор) — самостійно/в парах.
