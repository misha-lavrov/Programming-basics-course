# Встановлення інструментів. Перша програма

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/020-instrumenty-persha-prohrama.md`
**Тривалість:** 1.5–2 год (закладайте буфер — встановлення на різних машинах часто йде нерівномірно)
**Статус:** 🟢 розписано детально

## Опис
JDK, IntelliJ IDEA, як компілюється і виконується код, Hello World.

## Мета заняття
- Встановити JDK та IntelliJ IDEA Community на свій комп'ютер
- Розуміти на базовому рівні, як виконується Java-код (`.java` → `.class` → JVM)
- Написати і запустити свою першу програму
- Впевнено орієнтуватись в базовому інтерфейсі IDE (проєкт, файл, запуск)

## Підготовка викладача (перед заняттям)
- **Розіслати цю інструкцію студентам за 2–3 дні до заняття** з проханням встановити JDK та IntelliJ IDEA заздалегідь удома, де інтернет швидший і немає обмежень на встановлення ПЗ. На занятті — лише перевірка й допомога тим, у кого не вийшло. Це найбільше заощаджує час.
- Перевірити, чи на аудиторних комп'ютерах (якщо працюєте там) є права адміністратора для встановлення ПЗ, або чи потрібне ПЗ вже встановлене лаборантом заздалегідь.
- Мати напоготові файл-інсталятор JDK і IntelliJ на флешці — на випадок повільного/відсутнього інтернету в аудиторії.

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Сказати: «Сьогодні кожен з вас за цю пару встановить середовище розробки, яким користуються мільйони розробників у світі, і запустить свою першу справжню програму». Коротко розказати про традицію: `Hello World` — перша програма практично кожного розробника незалежно від мови програмування, свого роду "ритуал посвяти".

### 2. Коротка теорія (15–20 хв)
**Що таке JDK.** JDK (Java Development Kit) — набір інструментів для написання, компіляції та запуску Java-коду. Без нього комп'ютер не розуміє, що робити з файлом `.java`.

**Що таке IDE.** IDE (Integrated Development Environment, інтегроване середовище розробки) — зручна програма-редактор, яка об'єднує в одному вікні: написання коду з підсвіткою помилок, компіляцію, запуск, налагодження. Теоретично можна писати код у Блокноті й компілювати через командний рядок, але це незручно — тому користуємось IntelliJ IDEA.

**Як виконується Java-код (проста аналогія):**
1. Пишемо код у файлі `Program.java` — це текст, зрозумілий людині.
2. Компілятор (частина JDK) перетворює його на байт-код у файл `Program.class` — це вже не зрозумілий людині набір інструкцій, зате зрозумілий Java Virtual Machine (JVM).
3. JVM виконує цей байт-код на конкретному комп'ютері — Windows, Mac чи Linux.

Саме тому Java описують фразою **"write once, run anywhere"** (написав один раз — запускається будь-де): один і той самий `.class`-файл виконується на будь-якій системі, де встановлена JVM, без переписування коду.

### 3. Демонстрація / встановлення (основна частина заняття)

> Якщо студенти встановили все вдома заздалегідь (за розісланою інструкцією) — цей розділ перетворюється на швидку перевірку (крок 2) та живий розбір Hello World (нижче), а вивільнений час іде на практику.

#### Крок 1. Встановлення JDK (Windows)
1. Відкрити браузер і перейти на [adoptium.net](https://adoptium.net).
2. На сторінці буде велика кнопка з написом на кшталт "Latest LTS Release" і номером версії (на момент написання — JDK 21). Натиснути її — сайт сам визначить Windows і почне завантаження `.msi`-файлу.
3. Відкрити завантажений файл (папка "Завантаження" / "Downloads") подвійним кліком.
4. У вікні інсталятора натискати "Next", нічого не змінюючи.
5. На кроці "Custom Setup" переконатись, що увімкнені пункти **"Set JAVA_HOME variable"** і **"JavaSoft (Oracle) registry keys"** — зазвичай вони увімкнені за замовчуванням. Саме завдяки ним система та IntelliJ автоматично "бачитимуть" встановлену Java.
6. Натиснути "Install", дочекатись завершення, натиснути "Finish".

#### Крок 2. Перевірка встановлення JDK
1. Натиснути `Win + R`, ввести `cmd`, натиснути Enter — відкриється командний рядок.
2. Ввести команду `java -version` і натиснути Enter.
3. Якщо все встановилось правильно — з'явиться щось на кшталт `openjdk version "21.0.x" ...`.
4. Якщо з'явилась помилка на кшталт `"java" не є внутрішньою або зовнішньою командою` — перезавантажити комп'ютер і спробувати ще раз (Windows не завжди одразу підхоплює нову змінну середовища після встановлення). Якщо не допомогло — покликати викладача.

#### Крок 3. Встановлення IntelliJ IDEA Community Edition
1. Перейти на [jetbrains.com/idea/download](https://www.jetbrains.com/idea/download).
2. Переконатись, що обрана версія для Windows.
3. У колонці **Community** (це безкоштовна версія — саме вона потрібна, не платна Ultimate) натиснути "Download".
4. Запустити завантажений `.exe`-інсталятор.
5. Можна залишити всі опції за замовчуванням; корисно увімкнути створення ярлика на робочому столі.
6. Натискати "Next" → "Install" → дочекатись завершення → "Finish".

#### Крок 4. Перший запуск і створення проєкту
1. Запустити IntelliJ IDEA.
2. При першому запуску буде запропоновано обрати тему оформлення (Light/Dark — на смак) — це не принципово.
3. На стартовому екрані натиснути **"New Project"**.
4. У полі "Name" ввести, наприклад, `gurtok-java`.
5. У списку "Language" обрати **Java**.
6. У списку "Build system" обрати **IntelliJ** (найпростіший варіант для старту, без Maven/Gradle — до них дійдемо пізніше).
7. У полі "JDK" має автоматично з'явитись щойно встановлена версія. Якщо список порожній — натиснути "Add JDK" і вказати шлях (зазвичай `C:\Program Files\Eclipse Adoptium\jdk-21.x.x-hotspot`).
8. Натиснути **"Create"**.

#### Крок 5. Перший клас і Hello World
1. Зліва в панелі Project розгорнути `gurtok-java` → `src`.
2. Клацнути правою кнопкою миші на `src` → **New → Java Class**.
3. Ввести ім'я `HelloWorld`, натиснути Enter.
4. У файлі, що відкрився, видалити автозгенерований вміст і передрукувати (не копіювати — саме передрукувати, це важливо для звикання до синтаксису) код з [`HelloWorld.java`](src/020-instrumenty-persha-prohrama/HelloWorld.java).
5. Запустити програму: клацнути на зелений трикутник ▶ ліворуч від рядка `public static void main`, або натиснути `Ctrl + Shift + F10`.
6. Внизу відкриється панель "Run" з результатом: `Hello, World!`.

#### Примітка для macOS
Аналогічний процес: JDK — `.pkg`-інсталятор з adoptium.net (обрати macOS), встановити подвійним кліком. IntelliJ IDEA — `.dmg` з jetbrains.com, перетягнути іконку в папку Applications. Перевірка версії Java — через застосунок "Термінал" (Terminal), та сама команда `java -version`.

**Код для цього кроку:** [`HelloWorld.java`](src/020-instrumenty-persha-prohrama/HelloWorld.java) — файл містить докладні коментарі по кожному рядку, варто відкрити й прочитати їх разом із групою після першого запуску.

### 4. Керована практика (20–30 хв)
1. Кожен студент, у кого ще не встановлено — встановлює JDK та IntelliJ IDEA за кроками вище; викладач і ті, хто вже впорався, допомагають іншим.
2. Кожен створює клас `HelloName` (New → Java Class) і повторює приклад [`HelloName.java`](src/020-instrumenty-persha-prohrama/HelloName.java) — виводить власне ім'я замість "Олексію" і додає ще один рядок тексту (наприклад, звідки він/вона).
3. Запустити, переконатись, що бачать свій результат у панелі Run.

### 5. Самостійна практика / челендж (20–30 хв)
- **ASCII-малюнок.** Створити клас `AsciiStars` за прикладом [`AsciiStars.java`](src/020-instrumenty-persha-prohrama/AsciiStars.java), запустити, а потім самостійно домалювати ще один "поверх" трикутника додатковими рядками `println`.
- **print проти println.** Попросити студентів самостійно спробувати замінити кілька `println` на `print` у своєму коді й запустити — побачити різницю (println переводить рядок, print — ні).
- **Знайди й виправ помилку.** Створити клас `CompileError` за прикладом [`CompileError.java`](src/020-instrumenty-persha-prohrama/CompileError.java), запустити — побачити помилку компіляції. Завдання: самостійно прочитати повідомлення про помилку, зрозуміти, чого не вистачає (пропущена крапка з комою), і виправити. Це нормальна й важлива навичка — надалі доведеться робити це щодня.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити, з якими труднощами зіткнулись при встановленні, показати, куди писати за допомогою (спільний чат групи). Наголосити: проблеми з середовищем на старті — це нормально, з ними стикаються всі, і вміння самостійно розібратись у помилці — вже частина навички програміста.
