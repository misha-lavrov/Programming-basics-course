# Встановлення JDK та IntelliJ IDEA (інструкція для дому)

**Блок:** Блок 1. Старт і основи програмування
**Код файлу:** `010-osnovy-java/015-vstanovlennia-jdk-ta-idea.md`
**Для чого:** підготувати комп'ютер до заняття [020 — Встановлення інструментів. Перша програма](020-instrumenty-persha-prohrama.md). Якщо все встановите вдома заздалегідь — на занятті одразу писатимемо код, а не чекатимемо завантажень.
**Час:** 15–25 хв (залежить від інтернету).

Потрібно встановити дві речі:

1. **JDK** — набір інструментів, без якого комп'ютер не вміє запускати Java-код.
2. **IntelliJ IDEA** — програма (середовище розробки, IDE), у якій ми писатимемо код.

Порядок: **спочатку JDK, потім IntelliJ IDEA.**

---

## Частина 1. Встановлення JDK (Amazon Corretto 25)

### Яку версію і який дистрибутив обрати

- **Версія — JDK 25.** Це LTS-версія (Long-Term Support): для неї довго виходять оновлення, її використовують у реальних проєктах. Вийшла вона у вересні 2025 і підтримується до 2028 року. JDK 27 теж уже існує, але це «звичайна» версія з коротким терміном підтримки — для навчання вона не дає переваг, тому беремо 25.
- **Дистрибутив — Amazon Corretto.** JDK існує у кількох збірках від різних компаній (Corretto від Amazon, Temurin від Eclipse, Oracle JDK). Усі вони з одного відкритого коду й для навчання працюють однаково. Corretto обрано тому, що він безкоштовний, без ліцензійних нюансів, має звичайний `.msi`-інсталятор для Windows і його підтримує велика компанія. Oracle JDK теж можна, але в нього складніші ліцензійні умови — для старту це зайва морока.

### Windows

1. Завантажте інсталятор за прямим посиланням:
   **[amazon-corretto-25-x64-windows-jdk.msi](https://corretto.aws/downloads/latest/amazon-corretto-25-x64-windows-jdk.msi)**
   (це постійне посилання на останню версію Corretto 25; усі інші варіанти — на [сторінці завантажень](https://docs.aws.amazon.com/corretto/latest/corretto-25-ug/downloads-list.html)).
2. Відкрийте завантажений файл подвійним кліком (папка «Завантаження» / Downloads).
3. У вікні майстра встановлення натискайте **Next**, нічого не змінюючи (шлях за замовчуванням — `C:\Program Files\Amazon Corretto\`). Наприкінці натисніть **Install** і **Finish**. Якщо Windows запитає дозвіл на внесення змін — погодьтесь.
4. **Перевірте встановлення.** Натисніть `Win + R`, введіть `cmd`, натисніть Enter. У вікні командного рядка введіть:

   ```
   java -version
   ```

   Має з'явитись щось схоже на:

   ```
   openjdk version "25.0.x" ... LTS
   OpenJDK Runtime Environment Corretto-25.0.x...
   ```

   Головне — що там є слова `Corretto` і `25`.

### Якщо `java -version` видає помилку

Повідомлення на кшталт `"java" не є внутрішньою або зовнішньою командою` означає, що Windows ще не знає, де лежить Java. Спробуйте по черзі:

1. **Закрийте командний рядок і відкрийте новий** (а якщо не допомогло — перезавантажте комп'ютер). Windows підхоплює нові налаштування лише у щойно відкритих вікнах.
2. Якщо не допомогло — додайте Java вручну (за [офіційною інструкцією Corretto](https://docs.aws.amazon.com/corretto/latest/corretto-25-ug/windows-install.html)):
   1. Натисніть `Win`, почніть вводити **«Змінні середовища»** (Environment Variables) і відкрийте «Редагування системних змінних середовища».
   2. Натисніть кнопку **«Змінні середовища…»**.
   3. У верхньому списку («Змінні користувача») натисніть **«Створити…»**: ім'я — `JAVA_HOME`, значення — шлях до встановленої папки, наприклад `C:\Program Files\Amazon Corretto\jdk25.0.4_10` (відкрийте `C:\Program Files\Amazon Corretto\` у Провіднику й подивіться точну назву папки всередині).
   4. У тому ж списку знайдіть змінну **Path**, натисніть «Змінити…» → «Створити» і додайте рядок `%JAVA_HOME%\bin`. Підтвердіть усі вікна кнопкою **OK**.
   5. Відкрийте **новий** командний рядок і знову введіть `java -version`.
3. Якщо й це не допомогло — напишіть мені в Telegram, розберемося разом (на занятті теж можна підійти).

### macOS

Завантажте `.pkg` з [сторінки завантажень Corretto 25](https://docs.aws.amazon.com/corretto/latest/corretto-25-ug/downloads-list.html) (для Mac з чипом M1/M2/M3/M4 — рядок **macOS aarch64**, для старіших Intel — **macOS x64**), відкрийте і пройдіть майстра встановлення. Перевірка — через застосунок «Термінал» (Terminal) тією ж командою `java -version`.

### Запасний варіант: JDK прямо з IntelliJ IDEA

Якщо з окремим встановленням JDK не склалось, IntelliJ IDEA вміє завантажити JDK сама: під час створення проєкту в полі **JDK** оберіть **Download JDK…** → у списку «Vendor» вкажіть **Amazon Corretto**, у «Version» — **25** → **Download**. Але все ж краще спробувати встановити за інструкцією вище.

## Частина 2. Встановлення IntelliJ IDEA

### Важлива зміна: «Community Edition» більше не існує окремо

Раніше IntelliJ IDEA мала дві версії: безкоштовну **Community** і платну **Ultimate**. Починаючи з версії 2025.3 JetBrains об'єднала їх в **один продукт — просто «IntelliJ IDEA»**. Для нас це нічого не ускладнює:

- усе, що було у Community, **лишається безкоштовним** (і для навчання, і для комерційної роботи);
- **акаунт чи реєстрація для безкоштовного користування не потрібні**;
- на старті програма може запропонувати 30-денний пробний період платних функцій. Нам вони не потрібні: коли пробний період закінчиться, IDE просто продовжить працювати в безкоштовному режимі з усім, що потрібно для Java. Нічого платити чи вводити не треба.

Тому, якщо десь у відео чи статтях бачите «Community Edition» — це та сама безкоштовна частина, яка тепер входить в єдину програму.

### Windows

1. Відкрийте [jetbrains.com/idea/download](https://www.jetbrains.com/idea/download/) і переконайтесь, що обрано **Windows** (сайт зазвичай визначає систему сам). Якщо у вас Windows на процесорі ARM — оберіть відповідний варіант зі списку.
2. Натисніть **Download** і дочекайтесь завершення завантаження `.exe`-файлу (він великий, тож краще качати вдома на нормальному інтернеті, а не на мобільному).
3. Запустіть завантажений файл. У майстрі встановлення натискайте **Next**; корисно поставити галочку **Create Desktop Shortcut** (ярлик на робочому столі). Далі **Install** → **Finish**.
4. Запустіть IntelliJ IDEA. Можливі вікна на першому запуску:
   - угода користувача (User Agreement) — прочитайте і прийміть, без цього програма не запуститься;
   - запит про передачу анонімної статистики — **на ваш розсуд**, можна відмовитись;
   - вибір теми (світла / темна) — це суто смак.
5. **Вхід в акаунт JetBrains не потрібен.** Якщо програма пропонує «Log in» чи «Start trial» — це можна пропустити / закрити.

### macOS

Завантажте `.dmg` (оберіть **Apple Silicon** для Mac з чипами M1–M4 або **Intel** для старіших), відкрийте його й перетягніть іконку IntelliJ IDEA в папку **Applications**.

## Частина 3. Швидка перевірка, що все готово

- [ ] `java -version` у командному рядку показує Corretto 25.
- [ ] IntelliJ IDEA запускається і показує стартовий екран з кнопкою **New Project**.

Якщо обидва пункти виконані — ви готові до заняття. Створювати проєкт і писати першу програму будемо разом на занятті.

## Не вийшло? Це нормально

Проблеми з встановленням ПЗ на старті — звичайна справа, з ними стикаються всі, навіть досвідчені розробники. Не соромтесь питати: напишіть у Telegram-чат, що саме бачите на екрані (бажано зі скріншотом або текстом помилки). На занятті на комп'ютерах у коледжі все теж буде встановлено, тож без встановленого ПЗ ви не залишитесь.
