# Умовні конструкції

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/050-umovni-konstruktsii.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
if / else / else if, switch.

## Мета заняття
- Вміти писати `if / else if / else` конструкції
- Розуміти, коли доцільно використовувати `switch`
- Вміти комбінувати умови з логічними операторами з попереднього заняття

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Коротка інтерактивна гра «якби я був програмою»: ведучий озвучує умови вголос («якщо на вулиці дощ — піднімаєте руку», «якщо сьогодні п'ятниця — плескаєте в долоні», «якщо ви снідали сьогодні — встаєте»), студенти виконують. Після гри провести пряму паралель: «Те, що ви щойно робили — це і є `if` з життя: перевірка умови й дія в залежності від результату».

### 2. Коротка теорія (15–20 хв)
**Синтаксис `if / else if / else`:**
```java
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'F';
}
```
Умови перевіряються по черзі зверху вниз; виконується блок першої умови, що виявилась `true`, решта — пропускаються.

**Вкладені умови** — `if` всередині іншого `if`, коли одна перевірка залежить від іншої. Використовувати обережно: занадто глибока вкладеність важко читається.

**`switch-case`** — зручний, коли потрібно порівняти одну змінну з набором конкретних значень (наприклад, номер дня тижня чи символ команди):
```java
switch (day) {
    case 1:
        dayName = "Понеділок";
        break;
    case 2:
        dayName = "Вівторок";
        break;
    default:
        dayName = "Невідомий день";
}
```
**Важливо:** `break` зупиняє виконання `switch` після знайденого `case`. Якщо його забути, виконання «провалюється» у наступний `case` («fall-through») — це не завжди помилка (іноді так роблять навмисно), але для новачків це найчастіша неочікувана поведінка, тому спершу привчаємось завжди ставити `break`.

**Тернарний оператор `? :`** — компактна альтернатива простому `if-else` в одному рядку: `String result = (age >= 18) ? "дорослий" : "неповнолітній";`. Показати як факт, не наполягати на використанні одразу.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати два приклади:

### 4. Керована практика (20–30 хв)
Разом написати [`ChatBotStub.java`](src/050-umovni-konstruktsii/ChatBotStub.java) — заглушку простого «чат-бота»: зчитати команду користувача текстом і через `switch` вивести різні репліки залежно від введеного слова.

### 5. Самостійна практика / челендж (20–30 хв)
- Написати [`BmiCalculator.java`](src/050-umovni-konstruktsii/BmiCalculator.java) — калькулятор індексу маси тіла з категоріями (недостатня вага / норма / надлишкова вага / ожиріння) через вкладені `if`.
  **Практична пастка, вартий уваги коментар у файлі:** на комп'ютері з українською локаллю `Scanner.nextDouble()` за замовчуванням очікує кому як розділювач дробової частини (`1,75`), а не крапку (`1.75`), як усюди в написаному коді — інакше програма впаде з помилкою `InputMismatchException`. У прикладі це виправлено викликом `.useLocale(Locale.US)` — гарна нагода показати студентам, що подібні несподіванки, пов'язані з локальними налаштуваннями системи, трапляються в реальній розробці регулярно.
- Челендж: [`SwitchCalculator.java`](src/050-umovni-konstruktsii/SwitchCalculator.java) — калькулятор, який приймає символ операції (`+ - * /`) і два числа, і виконує потрібну дію через `switch`.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: коли обирати `if-else`, а коли `switch` — єдиної «правильної» відповіді немає, це питання зручності читання коду. Якщо перевіряється багато різних умов (діапазони, комбінації) — `if-else`; якщо порівнюється одна змінна з конкретними значеннями — `switch`.
