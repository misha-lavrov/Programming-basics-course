# Цикли (loops)

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/060-tsykly.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
for, while, do-while.

## Мета заняття
- Розуміти, навіщо потрібні цикли і як вони скорочують код
- Вміти писати `for`, `while`, `do-while`
- Розуміти ризик нескінченного циклу і базово знати `break`/`continue`

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Питання групі: «Як вивести числа від 1 до 100 без циклів?» Дати кілька секунд подумати, потім показати абсурдність ідеї писати 100 рядків `println()` вручну. Одразу запустити [`SumToN.java`](src/060-tsykly/SumToN.java) з великим числом (наприклад 1000000) — показати, що цикл рахує суму мільйона чисел практично миттєво.

### 2. Коротка теорія (15–20 хв)
**`for`** — використовується, коли заздалегідь відомо, скільки разів треба повторити дію (є лічильник):
```java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```
Три частини в дужках: початкове значення лічильника (`int i = 1`), умова продовження (`i <= 10`), крок після кожної ітерації (`i++`).

**`while`** — використовується, коли повторюємо, поки виконується умова, а кількість повторень наперед невідома:
```java
while (count > 0) {
    System.out.println(count);
    count--;
}
```
Умова перевіряється **до** виконання тіла циклу — якщо вона одразу хибна, тіло не виконається жодного разу.

**`do-while`** — те саме, що `while`, але умова перевіряється **після** виконання тіла — тобто тіло циклу виконається хоча б один раз, навіть якщо умова одразу хибна.

**`break` і `continue`** (коротко, як факт на майбутнє): `break` достроково завершує цикл повністю; `continue` пропускає лише поточну ітерацію і переходить до наступної.

**Нескінченний цикл** — поширена помилка новачків: якщо умова циклу ніколи не стає хибною (наприклад, забули `count--`), програма "зависає". Якщо це трапилось під час заняття — показати, як зупинити виконання в IntelliJ IDEA (червоний квадратик "Stop" біля панелі Run).

### 3. Демонстрація / live-coding (15–20 хв)
Два приклади:
1. [`MultiplicationTable.java`](src/060-tsykly/MultiplicationTable.java) — таблиця множення для введеного числа (`for`).
2. [`RocketCountdown.java`](src/060-tsykly/RocketCountdown.java) — зворотний відлік запуску ракети «5, 4, 3, 2, 1, старт!» через `do-while` — наочний приклад, коли тіло має виконатись хоч раз.

### 4. Керована практика (20–30 хв)
Разом написати [`SumToN.java`](src/060-tsykly/SumToN.java) — цикл, який рахує суму чисел від 1 до N, де N вводить користувач.

### 5. Самостійна практика / челендж (20–30 хв)
- [`EvenNumbersInRange.java`](src/060-tsykly/EvenNumbersInRange.java) — вивести всі парні числа в заданому діапазоні.
- Челендж: [`StarTriangle.java`](src/060-tsykly/StarTriangle.java) — намалювати трикутник із зірочок через вкладені цикли (цикл усередині циклу). Простий, але візуально приємний результат — гарна мотивація показати сусідові по парті.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити приклади циклів із життя (плейлист, що повторюється по колу, дні тижня, будильник щоранку). Ще раз наголосити на ризику нескінченного циклу і як його розпізнати.

## Домашнє завдання (необов'язково)
Побудувати «піраміду» з чисел (наприклад, кожен рядок — зростаюча кількість цифр, за аналогією до `StarTriangle.java`, але з цифрами замість зірочок). Спробувати вдома самостійно розв'язати класичну задачу FizzBuzz (від 1 до 100: кратне 3 → "Fizz", кратне 5 → "Buzz", кратне обом → "FizzBuzz") — знадобиться на наступному занятті.
