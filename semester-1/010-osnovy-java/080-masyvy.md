# Масиви (arrays)

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/080-masyvy.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Одновимірні масиви: створення, обхід, базові операції.

## Мета заняття
- Розуміти, навіщо потрібні масиви (зберігання багатьох значень одного типу разом)
- Вміти створювати, заповнювати й обходити одновимірний масив
- Знати про індексацію з 0 і типову помилку виходу за межі масиву

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
«Уявіть, що треба зберегти оцінки 30 студентів групи. Створювати 30 окремих змінних `grade1`, `grade2`, `grade3`...?» Дати групі уявити, як виглядав би такий код і як складно було б порахувати щось на кшталт середнього балу. Потім показати [`GradesAverage.java`](src/080-masyvy/GradesAverage.java) — та сама задача, розв'язана масивом і циклом за кілька рядків.

### 2. Коротка теорія (15–20 хв)
**Оголошення масиву:**
```java
int[] grades = new int[5];      // масив на 5 цілих чисел, усі поки що 0
int[] grades = {80, 92, 75};    // масив одразу заповнений значеннями
```

**Індексація з 0.** Перший елемент масиву — `grades[0]`, а не `grades[1]`. Останній елемент масиву довжини 5 — `grades[4]`. Це джерело найпоширенішої помилки новачків, варто окремо наголосити й повторити кілька разів.

**Властивість `.length`** повертає кількість елементів масиву: `grades.length`.

**Обхід масиву:**
```java
for (int i = 0; i < grades.length; i++) {
    System.out.println(grades[i]);
}
```
Коротший варіант — цикл `for-each`, коли не потрібен сам індекс, а лише значення:
```java
for (int grade : grades) {
    System.out.println(grade);
}
```

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`GradesAverage.java`](src/080-masyvy/GradesAverage.java): створення масиву оцінок, обхід циклом, підрахунок суми і середнього балу (з приведенням до `double`, щоб середнє не округлялось до цілого — та сама деталь, що й на занятті про оператори).

### 4. Керована практика (20–30 хв)
Разом написати [`MinMaxFinder.java`](src/080-masyvy/MinMaxFinder.java) — пошук максимального і мінімального значення в масиві. Ключова ідея: завести дві змінні `max` і `min`, ініціалізувати їх першим елементом масиву, а потім порівнювати з рештою елементів у циклі.

### 5. Самостійна практика / челендж (20–30 хв)
- [`WeeklyTemperatures.java`](src/080-masyvy/WeeklyTemperatures.java) — масив температур за тиждень: порахувати середню температуру і знайти найспекотніший день (використовуючи індекс максимуму, а не сам максимум, щоб можна було дістати відповідну назву дня з другого масиву).
- Челендж: [`ReverseArray.java`](src/080-masyvy/ReverseArray.java) — розвернути масив (реверс) без використання вбудованих методів, вручну через цикл, що обмінює елементи з початку і з кінця, рухаючись до середини.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити типову помилку `ArrayIndexOutOfBoundsException` — показати її наживо (звернутись до неіснуючого індексу) і пояснити, чому вона виникає. Згадати, що масив має фіксований розмір, заданий при створенні, і що далі в курсі (блок 3) буде гнучкіша структура — `ArrayList`, розмір якої можна змінювати.

## Домашнє завдання (необов'язково)
Написати програму, яка зчитує 5 чисел від користувача в масив (через `Scanner` у циклі) і виводить їх у зворотному порядку.
