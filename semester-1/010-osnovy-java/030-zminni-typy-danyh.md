# Змінні та типи даних (variables, data types)

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/030-zminni-typy-danyh.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Примітивні типи, оголошення змінних, введення/виведення через Scanner.

## Мета заняття
- Розуміти, що таке змінна і навіщо вона потрібна
- Знати основні примітивні типи Java (`int`, `double`, `boolean`, `char`) і коли який використовувати
- Вміти оголошувати змінні, присвоювати значення
- Вміти зчитувати ввід користувача через `Scanner`

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Аналогія на дошці: змінна — це підписана коробка, в яку можна щось покласти, а потім дістати або замінити вміст. Намалювати кілька коробок з підписами `name`, `age` і символічним вмістом. Одразу запустити [`Greeting.java`](src/030-zminni-typy-danyh/Greeting.java) наживо — програма запитує ім'я й вік і одразу видає персоналізоване привітання.

### 2. Коротка теорія (15–20 хв)
**Що таке змінна.** Змінна — це іменована ділянка пам'яті, в якій зберігається значення певного типу. Оголошуючи змінну, ми повідомляємо Java два факти: який тип даних там зберігатиметься і під яким іменем до нього звертатися.

**Основні примітивні типи:**
- `int` — ціле число (наприклад, `25`, `-3`, `0`). Найчастіше використовуваний числовий тип.
- `double` — дробове число (наприклад, `3.14`, `-0.5`). Використовує крапку як розділювач дробової частини, а не кому.
- `boolean` — логічне значення, лише `true` або `false`.
- `char` — один символ у одинарних лапках, наприклад `'A'`.
- `String` — рядок тексту у подвійних лапках, наприклад `"Привіт"`. Технічно це не примітивний тип, а клас, але для перших занять зручно вважати його "базовим" типом для роботи з текстом.

**Оголошення і присвоєння:**
```java
int age;       // оголошення — просто "заводимо коробку" без вмісту
age = 20;      // присвоєння значення
int score = 100; // оголошення + присвоєння одним рядком (найчастіший варіант)
```

**Іменування змінних.** Прийнято використовувати `camelCase` (перше слово з малої літери, кожне наступне — з великої): `userAge`, `favoriteColor`. Ім'я має бути зрозумілим — `age`, а не `a` чи `x`.

**Scanner — зчитування вводу користувача.** Щоб програма могла отримати дані від користувача через консоль, використовуємо клас `Scanner`:
```java
Scanner scanner = new Scanner(System.in);
int age = scanner.nextInt();       // зчитати ціле число
double price = scanner.nextDouble(); // зчитати дробове число
String line = scanner.nextLine();  // зчитати весь рядок тексту
```

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`Greeting.java`](src/030-zminni-typy-danyh/Greeting.java) рядок за рядком: створення `Scanner`, зчитування імені через `nextLine()`, зчитування віку через `nextInt()`, побудова привітання через конкатенацію (`+`). Наголосити, що оператор `+` між рядком і числом автоматично перетворює число на текст.

### 4. Керована практика (20–30 хв)
Разом написати [`SimpleCalculator.java`](src/030-zminni-typy-danyh/SimpleCalculator.java): зчитати два цілі числа через `Scanner` і вивести їхню суму, різницю та добуток.

### 5. Самостійна практика / челендж (20–30 хв)
- Написати програму «профіль користувача» за прикладом [`UserProfile.java`](src/030-zminni-typy-danyh/UserProfile.java): зчитати ім'я, вік і улюблену мову програмування, вивести структуроване summary.
- **Важлива деталь з прикладу:** якщо після `scanner.nextInt()` одразу викликати `scanner.nextLine()`, воно зчитає порожній залишок рядка замість очікуваного тексту. Рішення — викликати "порожній" `scanner.nextLine()` одразу після `nextInt()`, щоб "з'їсти" залишок. Це варто розібрати з групою на прикладі — практично кожен новачок хоч раз наступає на цю пастку.
- Челендж (вбудований у той самий приклад): порахувати, скільки приблизно днів студент живе на світі (`вік × 365`).

### 6. Рефлексія та підсумок (5–10 хв)
Швидкий усний квіз: «який тип обрати для...» (кількість людей у групі, ціна товару, чи йде дощ, перша літера імені). Мета — закріпити інтуїцію вибору типу, а не формальне визначення.

## Домашнє завдання (необов'язково)
Написати програму-конвертер валют: ввести суму в гривнях (`double`), вивести еквівалент у доларах за фіксованим курсом (курс — просто число, записане прямо в коді).
