# Рядки (strings)

**Блок:** Блок 1. Старт і основи програмування
**Код заняття:** `010-osnovy-java/090-riadky.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Клас String, основні методи роботи з текстом.

## Мета заняття
- Знати основні методи класу `String` (`length`, `charAt`, `substring`, `indexOf`, `toUpperCase`/`toLowerCase`, `equals`, `contains`, `split`)
- Розуміти на базовому рівні, що рядки в Java незмінні (immutable)
- Вміти комбінувати роботу з рядками, циклами і умовами

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Наживо показати готовий результат, до якого прийдемо на цьому занятті — запустити [`PalindromeChecker.java`](src/090-riadky/PalindromeChecker.java) і перевірити кілька слів («око», «шалаш», «привіт»). Зацікавити практичним і трохи "магічним" застосуванням роботи з текстом — програма ніби "розуміє" мову.

### 2. Коротка теорія (15–20 хв)
**`String` як послідовність символів.** Кожен рядок можна уявити як пронумерований (з 0) ряд окремих символів.

**Основні методи:**
- `word.length()` — кількість символів у рядку.
- `word.charAt(i)` — символ за індексом `i`.
- `word.substring(a, b)` — частина рядка від індексу `a` до `b` (не включно).
- `word.indexOf("текст")` — позиція першого входження підрядка, або `-1`, якщо не знайдено.
- `word.toUpperCase()` / `word.toLowerCase()` — перетворення регістру.
- `word.contains("текст")` — чи містить рядок підрядок.
- `word.replace("а", "б")` — заміна всіх входжень.
- `word.split(" ")` — розбиває рядок на масив підрядків за роздільником.
- `word.trim()` — прибирає пробіли з початку і кінця рядка.

**`equals()` проти `==` — важливо наголосити одразу.** Для порівняння **вмісту** двох рядків завжди використовуємо `.equals()`:
```java
if (word.equals("привіт")) { ... }   // правильно
if (word == "привіт") { ... }        // ненадійно, можна отримати неочікуваний результат
```
`==` порівнює, чи це один і той самий об'єкт у пам'яті, а не чи однаковий текст — це одна з найпоширеніших пасток новачків у Java.

**Незмінність (immutability).** Рядки в Java не змінюються "на місці" — кожен метод на кшталт `toUpperCase()` не змінює оригінальний рядок, а повертає **новий**. Тобто `word.toUpperCase();` без присвоєння результату нічого не змінить у `word`.

### 3. Демонстрація / live-coding (15–20 хв)
Разом написати [`CountVowels.java`](src/090-riadky/CountVowels.java) — програма рахує кількість голосних букв у введеному слові, обходячи рядок по символах через `charAt()` у циклі й перевіряючи належність до рядка `"аеєиіїоуюя"` через `indexOf()`.

### 4. Керована практика (20–30 хв)
Написати [`PalindromeChecker.java`](src/090-riadky/PalindromeChecker.java) — перевірку, чи є введене слово паліндромом (порівняти слово з розвернутою версією через `equals()`). У прикладі для розвороту рядка використовується `StringBuilder` — можна пояснити на рівні "готовий інструмент для розвороту рядка в один рядок коду", не заглиблюючись у деталі класу.

### 5. Самостійна практика / челендж (20–30 хв)
- [`WordCounter.java`](src/090-riadky/WordCounter.java) — порахувати кількість слів у реченні через `split(" ")`.
- Челендж: [`CaesarCipher.java`](src/090-riadky/CaesarCipher.java) — реалізувати спрощений шифр Цезаря (зсув кожної літери слова на задану кількість позицій по алфавіту). Приклад свідомо спрощений (лише малі латинські літери, без пробілів) — акцент на ідеї, а не на обробці всіх крайових випадків.

### 6. Рефлексія та підсумок (5–10 хв)
Ще раз наголосити на різниці `==` і `.equals()` для рядків. Запитати групу: «Якщо колись побачите в чужому коді `if (a == b)` для рядків — це, найімовірніше, помилка чи навмисне рішення?» — обговорити відповідь разом.
