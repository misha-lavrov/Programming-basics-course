# Колекції: Map / HashMap

**Блок:** Блок 3. Структури даних та алгоритми (основи)
**Код заняття:** `030-algorytmy-struktury-danyh/050-kolektsii-map-hashmap.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Пари ключ-значення, типові задачі.

## Мета заняття
- Розуміти ідею `Map`: зберігання даних як пар "ключ → значення"
- Вміти виконувати базові операції `HashMap`: `put`, `get`, `containsKey`, `remove`, `getOrDefault`
- Вміти розв'язати практичну задачу через `HashMap` (наприклад, підрахунок частоти)

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Запитати групу: «Пригадайте `WordCounter.java` з блоку 1 — рахували кількість СЛІВ у реченні. А якщо треба порахувати, скільки разів зустрічається КОЖНЕ конкретне слово?» Дати кілька секунд подумати, як це зробити масивами (складно — довелось би зберігати паралельно і слова, і лічильники, і перевіряти, чи слово вже зустрічалось). Запустити [`WordFrequency.java`](src/050-kolektsii-map-hashmap/WordFrequency.java).

### 2. Коротка теорія (15–20 хв)
**Що таке `Map`.** `Map` зберігає дані як пари "ключ → значення", де кожен ключ унікальний (не може повторюватись), а значення — будь-яке, в тому числі однакове для різних ключів.
```java
HashMap<String, Integer> frequency = new HashMap<>();
frequency.put("java", 1);        // додати пару ключ-значення
frequency.get("java");           // отримати значення за ключем (поверне 1)
frequency.containsKey("java");   // чи є такий ключ
frequency.remove("java");        // видалити пару за ключем
frequency.getOrDefault("java", 0); // значення за ключем, або 0, якщо ключа немає
```

**Чому `HashMap`, а не масив паралельних списків.** Доступ до значення за ключем у `HashMap` в середньому дуже швидкий (близько O(1) — константна складність, як обговорювали на занятті про Big O), незалежно від того, скільки всього пар зберігається. Це принципово інший компроміс, ніж масив чи `ArrayList`, де пошук за значенням вимагав би перебору (O(n)).

**Типова задача — підрахунок частоти.** Класичний патерн: «якщо ключ вже є — збільшити лічильник, якщо немає — додати з лічильником 1» — саме так побудований `WordFrequency.java`.

Разом розібрати [`PhoneBook.java`](src/050-kolektsii-map-hashmap/PhoneBook.java) — телефонна книга: `put`, `get` (в тому числі для неіснуючого ключа — поверне `null`, важливо це показати наживо), `remove`, `containsKey`.

Челендж: додати метод, що виводить усі товари, кількість яких менша за задане порогове значення ("товари, які закінчуються").

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: у яких реальних задачах з життя студентів природно напрошується структура "ключ → значення" (словник перекладу, оцінки за предметами, ціни товарів у магазині)?

## Домашнє завдання (необов'язково)
Написати програму, яка зчитує кілька оцінок студентів (ім'я + оцінка) і зберігає їх у `HashMap<String, Integer>`, а потім виводить ім'я студента з найвищою оцінкою (перебором `keySet()` або `entrySet()`).
