# Стек і черга (Stack, Queue)

**Блок:** Блок 3. Структури даних та алгоритми (основи)
**Код заняття:** `030-algorytmy-struktury-danyh/070-stek-cherga.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Концепції LIFO/FIFO, застосування на прикладах.

## Мета заняття
- Розуміти принцип LIFO (Stack) і FIFO (Queue)
- Вміти виконувати базові операції: `push`/`pop`/`peek` для `Stack`, `offer`/`poll`/`peek` для `Queue`
- Вміти застосувати `Stack` для практичної задачі (перевірка збалансованості дужок)

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Дві аналогії на дошці: **стос тарілок** — кладемо зверху, беремо теж зверху (останню покладену тарілку зніматимемо першою); **черга в магазині** — хто прийшов першим, того першим і обслужать. Запустити [`StackDemo.java`](src/070-stek-cherga/StackDemo.java) — показати, як `pop()` повертає елементи у ЗВОРОТНОМУ до додавання порядку.

### 2. Коротка теорія (15–20 хв)
**Stack (стек) — LIFO (Last In, First Out).** Останній доданий елемент буде вилучений першим.
```java
Stack<Integer> stack = new Stack<>();
stack.push(1);   // покласти на верх
stack.peek();    // подивитись на верхній елемент, не знімаючи
stack.pop();     // зняти й повернути верхній елемент
stack.isEmpty(); // чи стек порожній
```

**Queue (черга) — FIFO (First In, First Out).** Перший доданий елемент буде вилучений першим.
```java
Queue<String> queue = new LinkedList<>(); // Queue - інтерфейс, LinkedList - одна з реалізацій
queue.offer("A"); // стати в чергу
queue.peek();     // подивитись на першого в черзі, не видаляючи
queue.poll();     // забрати першого з черги
```

**Де це застосовується насправді.** Stack — скасування дій (Ctrl+Z у редакторах), історія переходів у браузері ("назад"), перевірка синтаксису (дужки, теги). Queue — черги завдань на виконання, обробка запитів у порядку надходження, черга друку.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`StackDemo.java`](src/070-stek-cherga/StackDemo.java) — базові операції плюс практичний приклад: розвернути рядок за допомогою стеку (покласти всі символи, потім знімати — вони вийдуть у зворотному порядку).

### 4. Керована практика (20–30 хв)
Разом розібрати [`QueueDemo.java`](src/070-stek-cherga/QueueDemo.java) — імітація черги обслуговування клієнтів, `offer`/`poll`/`peek`.

### 5. Самостійна практика / челендж (20–30 хв)
Розібрати [`BalancedParentheses.java`](src/070-stek-cherga/BalancedParentheses.java) — класична задача (часто зустрічається на технічних співбесідах): перевірка, чи збалансовані дужки у виразі, розв'язана саме через `Stack`. Челендж: розширити перевірку на кілька видів дужок одночасно — `()`, `[]`, `{}`.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: чому саме `Stack` природно підходить для перевірки дужок (кожна відкриваюча дужка "чекає" своєї пари в порядку LIFO — остання відкрита дужка має закритись першою).

## Домашнє завдання (необов'язково)
