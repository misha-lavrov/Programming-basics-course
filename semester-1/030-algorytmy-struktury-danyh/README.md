# Блок 3. Структури даних та алгоритми (основи)

Файли пронумеровані з кроком 10 (010–100) — це залишає місце, щоб вставити нове заняття
між існуючими (наприклад `015-...`), не перейменовуючи решту файлів блоку.

## Заняття

- [010] [Складність алгоритмів «на пальцях»](010-skladnist-algorytmiv.md) — Інтуїтивне пояснення Big O, чому це важливо.
- [020] [Сортування](020-sortuvannia.md) — Bubble sort, selection sort — ручна реалізація.
- [030] [Пошук](030-poshuk.md) — Лінійний та бінарний пошук.
- [040] [Колекції Java: List / ArrayList](040-kolektsii-list-arraylist.md) — Детальніше про методи, порівняно з масивом.
- [050] [Колекції: Map / HashMap](050-kolektsii-map-hashmap.md) — Пари ключ-значення, типові задачі.
- [060] [Колекції: Set / HashSet](060-kolektsii-set-hashset.md) — Унікальні елементи, застосування.
- [070] [Стек і черга (Stack, Queue)](070-stek-cherga.md) — Концепції LIFO/FIFO, застосування на прикладах.
- [080] [Обробка виключень (exceptions)](080-vynyatky-exceptions.md) — try/catch/finally, власні винятки.
- [090] [Робота з файлами (basic I/O)](090-robota-z-failamy.md) — Читання/запис у текстовий файл.
- [100] [Практичний чекпоінт №3](100-praktychnyi-chekpoint-3.md) — Розв'язання набору алгоритмічних задач (можна познайомити з Codewars/LeetCode-easy).
