# Колекції: Set / HashSet

**Блок:** Блок 3. Структури даних та алгоритми (основи)
**Код заняття:** `030-algorytmy-struktury-danyh/060-kolektsii-set-hashset.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Унікальні елементи, застосування.

## Мета заняття
- Розуміти ідею `Set`: колекція без повторюваних елементів
- Вміти виконувати базові операції `HashSet`: `add`, `contains`, `remove`, `retainAll`
- Вміти застосувати `HashSet` для практичних задач (унікальність, перетин множин)

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Запитати групу: «Як швидко прибрати повторювані елементи з масиву чисел?» Дати подумати над варіантом із вкладеними циклами (порівняти кожен з кожним — O(n²), уже знайома складність). Запустити [`UniqueLetters.java`](src/060-kolektsii-set-hashset/UniqueLetters.java) — показати рішення в кілька рядків.

### 2. Коротка теорія (15–20 хв)
**Що таке `Set`.** `Set` — колекція, що зберігає лише УНІКАЛЬНІ елементи: спроба додати значення, яке вже є в множині, просто ігнорується, без помилки.
```java
HashSet<Integer> unique = new HashSet<>();
unique.add(5);
unique.add(5); // нічого не станеться - 5 вже є
unique.contains(5); // true
unique.remove(5);
```

**Порівняння з `List`.** `List` (наприклад `ArrayList`) зберігає елементи В ПОРЯДКУ додавання і дозволяє дублікати. `Set` — навпаки: не гарантує порядку (`HashSet` конкретно — точно не гарантує), зате гарантує унікальність. Обирайте `Set`, коли важлива саме відсутність повторень, а порядок елементів не має значення.

**Операції над множинами.** `retainAll()` залишає в множині лише ті елементи, які є ТАКОЖ і в іншій множині — це перетин (спільні елементи) двох множин, класична математична операція над множинами, доступна "з коробки".

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`UniqueLetters.java`](src/060-kolektsii-set-hashset/UniqueLetters.java) — підрахунок унікальних букв у слові через `HashSet<Character>`.

### 4. Керована практика (20–30 хв)
Разом розібрати [`RemoveDuplicates.java`](src/060-kolektsii-set-hashset/RemoveDuplicates.java) — прибрати дублікати з масиву чисел, додавши всі елементи в `HashSet` (порівняти з альтернативним підходом через вкладені цикли O(n²) — наочно показати виграш у простоті коду).

### 5. Самостійна практика / челендж (20–30 хв)
Розібрати [`CommonElements.java`](src/060-kolektsii-set-hashset/CommonElements.java) — перетин двох множин навичок через `retainAll()`. Челендж: знайти елементи, які є ЛИШЕ в першій множині, але не в другій (підказка: метод `removeAll()`).

### 6. Рефлексія та підсумок (5–10 хв)
Підсумувати три вивчені колекції разом (`ArrayList`, `HashMap`, `HashSet`) — коротке практичне правило: список з порядком і дублікатами → `ArrayList`; пари ключ-значення → `HashMap`; лише унікальні значення без порядку → `HashSet`.
