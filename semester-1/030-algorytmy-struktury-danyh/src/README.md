# Приклади коду до занять блоку 3

Кожна підпапка тут відповідає одному файлу заняття (та сама назва, без розширення `.md`)
і містить готові, робочі `.java`-файли, на які заняття посилається.

## Як запустити приклад

**Варіант A — в IntelliJ IDEA (рекомендовано для занять):**
1. Відкрити папку потрібного заняття як проєкт (або додати файли до вже
   існуючого проєкту).
2. Відкрити файл з `main()` і клацнути на зелений трикутник ▶.
3. Результат з'явиться в панелі "Run" внизу.

**Варіант B — через термінал (Java 11+, без окремої компіляції):**
```
java -Dfile.encoding=UTF-8 ІмяФайлу.java
```

**Варіант C — через термінал (для кількох файлів в одній папці):**
```
javac -encoding UTF-8 *.java
java -Dfile.encoding=UTF-8 ІмяФайлу
```

## Заняття 090 (робота з файлами) — важливо

Приклади `WriteToFile.java`, `ReadFromFile.java` і `LineCounter.java` створюють і
читають файл `notes.txt` у поточній робочій директорії (там, звідки запущено
програму). Спершу обов'язково запустіть `WriteToFile.java` — інакше `ReadFromFile.java`
і `LineCounter.java` не знайдуть файл. В IntelliJ IDEA робочою директорією зазвичай
є корінь проєкту.

## Відома пастка: кирилиця і Windows-консоль

Ті самі дві проблеми, що й у попередніх блоках (детальніше — у `src/README.md`
блоку 1): `javac` без `-encoding UTF-8` може не прочитати кириличні коментарі;
вивід кирилиці в терміналі може "сипатись" без `-Dfile.encoding=UTF-8`. У IntelliJ
IDEA обидві проблеми, як правило, не виникають.

## Примітка про іменування

Ім'я файлу завжди збігається з іменем публічного класу всередині (правило Java).
Коментарі — українською; імена змінних, методів і класів — англійською. Файли
з поміткою "приклад розв'язку для викладача" призначені лише для викладача,
не роздавати студентам одразу.
