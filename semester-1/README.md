вставляти нові блоки/заняття, не збиваючи нумерацію решти.

## Формат заняття

Кожне заняття — 1.5–2 год, побудоване за єдиним шаблоном (хук → коротка теорія →
демо → керована практика → самостійна практика → рефлексія), з акцентом на практику,
а не теорію. Деталі — у файлі кожного заняття.
