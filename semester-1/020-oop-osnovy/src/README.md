# Приклади коду до занять блоку 2

Кожна підпапка тут відповідає одному файлу заняття (та сама назва, без розширення `.md`)
і містить готові, робочі `.java`-файли, на які заняття посилається.

Починаючи з цього блоку приклади частіше складаються з КІЛЬКОХ файлів, що працюють
разом: клас-модель (наприклад `Dog.java`) і окремий клас з `main()`, що його
використовує (наприклад `DogDemo.java`). Це звичайна практика в ООП-коді — не
помилка і не привід шукати `main()` в кожному файлі.

## Як запустити приклад

**Варіант A — в IntelliJ IDEA (рекомендовано для занять):**
1. Відкрити папку потрібного заняття як проєкт (або додати файли до вже
   існуючого проєкту з блоку 1).
2. Відкрити файл, що містить `main()` (зазвичай `...Demo.java`).
3. Клацнути на зелений трикутник ▶ ліворуч від рядка `public static void main`.
4. Результат з'явиться в панелі "Run" внизу.

**Важливо:** якщо клас-модель (наприклад `Dog.java`) і клас-демо (`DogDemo.java`)
лежать в одній папці — IntelliJ сам знайде і скомпілює обидва файли. Через
термінал так само: компілюйте/запускайте `...Demo.java`, а не файл моделі.

**Варіант B — через термінал (Java 11+, без окремої компіляції):**
```
java -Dfile.encoding=UTF-8 ІмяФайлуDemo.java
```
Однофайловий запуск (`java Файл.java`) підхоплює лише один файл — якщо приклад
складається з кількох `.java`-файлів в одній папці, використовуйте Варіант C.

**Варіант C — через термінал (класичний спосіб, працює для кількох файлів):**
```
javac -encoding UTF-8 *.java
java -Dfile.encoding=UTF-8 ІмяФайлуDemo
```
(перша команда компілює ВСІ `.java`-файли в поточній папці, друга — запускає конкретний клас)

## Відома пастка: кирилиця і Windows-консоль

Ті самі дві проблеми, що й у блоці 1 (детальніше — у `src/README.md` блоку 1):
1. `javac` без `-encoding UTF-8` може не прочитати кириличні коментарі.
2. Вивід кирилиці в терміналі може показуватись "кракозябрами" без `-Dfile.encoding=UTF-8`.

У IntelliJ IDEA обидві проблеми, як правило, не виникають.

## Примітка про іменування

Ім'я файлу завжди збігається з іменем публічного класу всередині (правило Java).
Коментарі — українською, для пояснення; імена змінних, методів і класів —
англійською, як прийнято в індустрії. Файли-приклади розв'язків для чекпоінтів
(з поміткою "не показувати студентам одразу") призначені лише для викладача.
