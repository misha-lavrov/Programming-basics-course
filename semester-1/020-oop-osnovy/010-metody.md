# Методи (methods)

**Блок:** Блок 2. Методи та основи ООП
**Код заняття:** `020-oop-osnovy/010-metody.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Оголошення, параметри, повернення значення, перевантаження.

## Мета заняття
- Розуміти, навіщо потрібні методи (уникнення повторення коду, розбиття задачі на менші шматки)
- Вміти оголошувати метод з параметрами і без, з поверненим значенням і без (`void`)
- Розуміти перевантаження методів (overloading)

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Запитати групу: «Пригадайте FizzBuzz із блоку 1 — а якщо цю саму перевірку "чи ділиться на число" довелось би повторювати в п'яти різних місцях програми? Копіювати той самий код п'ять разів?» Показати ідею: замість копіювання — написати один раз, назвати, і викликати за іменем звідки завгодно. Запустити [`Greet.java`](src/010-metody/Greet.java) — один і той самий метод викликається двічі з різними даними.

### 2. Коротка теорія (15–20 хв)
**Що таке метод.** Метод — це іменований, багаторазово використовуваний шматок коду. Усе, що студенти писали в `main()` досі, технічно теж перебуває всередині одного методу — просто спеціального, з якого JVM починає виконання програми.

**Оголошення методу без результату (`void`):**
```java
static void greetByName(String name) {
    System.out.println("Привіт, " + name + "!");
}
```
`void` означає «цей метод нічого не повертає, лише виконує дію». `name` — параметр: значення, яке метод отримує ззовні під час виклику.

**Метод, що повертає значення:**
```java
static int add(int x, int y) {
    return x + y;
}
```
Тип перед іменем методу (`int`) — тип значення, яке метод обов'язково поверне через `return`. Результат виклику можна одразу вивести, зберегти в змінну або використати в іншому обчисленні — це звичайне значення, як і будь-яке інше.

**`static` — поки що просто факт.** Усі методи в наших прикладах позначені `static`, бо викликаються прямо з `main()` (який теж `static`) без створення об'єкта. Детальніше, чому так, розберемо, коли дійдемо до класів і об'єктів (заняття 040) — поки досить запам'ятати, що це потрібно писати.

**Перевантаження методів (overloading).** Можна мати кілька методів з однаковим іменем, але різним набором параметрів (за кількістю або типами) — Java сама визначає, яку саме версію викликати, дивлячись на аргументи виклику.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати два приклади:
1. [`MathOperations.java`](src/010-metody/MathOperations.java) — методи, що повертають значення: `add`, `subtract`, `multiply`.
2. [`Overloading.java`](src/010-metody/Overloading.java) — три методи з іменем `sum`, але різними параметрами; показати, як Java обирає потрібний варіант залежно від переданих аргументів.

### 4. Керована практика (20–30 хв)
Разом дописати до `MathOperations.java` ще один метод — `divide(int x, int y)`, що повертає `double` (з приведенням типів, як на занятті про оператори в блоці 1), і викликати його з `main()`.

### 5. Самостійна практика / челендж (20–30 хв)
Написати [`MaxOfThree.java`](src/010-metody/MaxOfThree.java) — метод, що приймає три цілі числа і повертає найбільше з них. Підказка для тих, хто застряг: почати з порівняння лише двох чисел (як у `MinMaxFinder.java` з блоку 1), а потім додати третє.

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: чим метод відрізняється від просто «шматка коду, скопійованого в кілька місць»? (Відповідь: зміни треба вносити лише в одному місці; код читається зрозуміліше, коли розбитий на іменовані шматки з чіткою відповідальністю).

## Домашнє завдання (необов'язково)
Написати набір методів-конвертерів одиниць (наприклад, кілометри → милі, кілограми → фунти) і викликати кожен з `main()` з кількома різними значеннями.
