# Конструктори та методи класу

**Блок:** Блок 2. Методи та основи ООП
**Код заняття:** `020-oop-osnovy/050-konstruktory.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
this, конструктори з параметрами, перевантаження конструкторів.

## Мета заняття
- Розуміти, що таке конструктор і навіщо він потрібен
- Вміти писати конструктор з параметрами, використовуючи `this`
- Розуміти перевантаження конструкторів (кілька варіантів створення об'єкта)

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Нагадати попереднє заняття: щоб заповнити поля об'єкта `Dog`, довелось писати три окремі рядки (`firstDog.name = ...`, `firstDog.breed = ...`, `firstDog.age = ...`). Запитати: «А що, якщо забути заповнити один з рядків?» (Поле лишиться з порожнім/нульовим значенням за замовчуванням — потенційне джерело помилок). Показати рішення — запустити [`DogDemo.java`](src/050-konstruktory/DogDemo.java): тепер об'єкт створюється і одразу повністю заповнюється одним рядком.

### 2. Коротка теорія (15–20 хв)
**Що таке конструктор.** Конструктор — спеціальний метод, який автоматично викликається в момент `new ClassName(...)` і одразу заповнює поля нового об'єкта. Має те саме ім'я, що й клас, і не має типу результату (навіть не `void`):
```java
public class Dog {
    String name;
    String breed;
    int age;

    Dog(String name, String breed, int age) {
        this.name = name;
        this.breed = breed;
        this.age = age;
    }
}
```

**Навіщо `this`.** Параметри конструктора (`name`, `breed`, `age`) навмисно названі так само, як і поля класу — це зручно й читається природно. Але тоді виникає неоднозначність: `name = name` було б незрозуміло, яке саме "name" мається на увазі. `this.name` явно вказує: «поле САМЕ ЦЬОГО об'єкта, який зараз створюється», на відміну від просто `name` — параметра, переданого ззовні.

**Перевантаження конструкторів (constructor overloading).** Так само, як і зі звичайними методами (заняття 010), можна мати кілька конструкторів з різним набором параметрів — для різних сценаріїв створення об'єкта:
```java
Book(String title, String author, int pages) { ... }
Book(String title, String author) { ... pages = 0; }
```

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати пару [`Dog.java`](src/050-konstruktory/Dog.java) + [`DogDemo.java`](src/050-konstruktory/DogDemo.java) — порівняти з версією без конструктора з попереднього заняття (блок 040), наочно показавши, наскільки коротшим став код створення об'єкта.

### 4. Керована практика (20–30 хв)
Разом розібрати пару [`Book.java`](src/050-konstruktory/Book.java) + [`BookDemo.java`](src/050-konstruktory/BookDemo.java) — два перевантажені конструктори: повний (з кількістю сторінок) і скорочений (без сторінок, зі значенням за замовчуванням).

### 5. Самостійна практика / челендж (20–30 хв)
Розібрати й доповнити пару [`Rectangle.java`](src/050-konstruktory/Rectangle.java) + [`RectangleDemo.java`](src/050-konstruktory/RectangleDemo.java) — клас із методом `area()` і перевантаженим конструктором для окремого випадку — квадрата (приймає лише одну сторону замість ширини й висоти). Челендж: додати ще один метод `perimeter()` (периметр).

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: чому конструктор — це, по суті, теж метод, тільки особливий? Що змінилось у зручності роботи з об'єктами порівняно з минулим заняттям?
