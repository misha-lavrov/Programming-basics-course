# Багатовимірні масиви та ArrayList (вступ)

**Блок:** Блок 2. Методи та основи ООП
**Код заняття:** `020-oop-osnovy/030-bagatovymirni-masyvy-arraylist.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Двовимірні масиви, перше знайомство з ArrayList.

## Мета заняття
- Вміти створювати й обходити двовимірний масив (масив масивів)
- Знати базові операції `ArrayList`: `add`, `get`, `remove`, `size`
- Розуміти головну відмінність `ArrayList` від звичайного масиву — гнучкий розмір

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Намалювати на дошці таблицю (сітку) 3×3 — запитати: «Як зберегти таке в одному масиві?» Дати кілька секунд подумати, потім запустити [`Grid2D.java`](src/030-bagatovymirni-masyvy-arraylist/Grid2D.java) — двовимірний масив, що виводить поле для хрестиків-нуликів.

### 2. Коротка теорія (15–20 хв)
**Двовимірний масив** — це, по суті, масив масивів: кожен елемент зовнішнього масиву сам є масивом.
```java
int[][] grid = new int[3][3];        // 3 рядки по 3 стовпці, усі 0
int[][] grid = {{1, 2}, {3, 4}};     // одразу заповнений
grid[0][1] = 99;                     // перший індекс - рядок, другий - стовпець
```
Обхід — цикл усередині циклу: зовнішній перебирає рядки, внутрішній — стовпці в кожному рядку.

**`ArrayList` — масив, що росте.** Головна незручність звичайного масиву — фіксований розмір, заданий наперед. `ArrayList` вирішує цю проблему:
```java
ArrayList<String> list = new ArrayList<>();
list.add("Молоко");          // додати елемент в кінець
list.add(0, "Терміново");    // додати на конкретну позицію
list.get(0);                 // отримати елемент за індексом
list.remove("Молоко");       // видалити за значенням
list.size();                 // кількість елементів (аналог .length, але метод, а не поле)
```
**Важливо:** `ArrayList<String>` — у кутових дужках вказується тип елементів, і це має бути тип-обгортка (`String`, `Integer`, а не примітивний `int`) — деталі цього поки не заглиблюємо, просто запам'ятовуємо як правило.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`GradesMatrix.java`](src/030-bagatovymirni-masyvy-arraylist/GradesMatrix.java) — двовимірний масив оцінок (рядок — студент, стовпець — предмет), підрахунок середнього балу кожного студента через вкладений цикл.

### 4. Керована практика (20–30 хв)
Разом дописати до `GradesMatrix.java` пошук студента з найвищим середнім балом (порівнюючи середні значення, порахован і в попередньому кроці).

### 5. Самостійна практика / челендж (20–30 хв)
Розібрати й доповнити [`ShoppingList.java`](src/030-bagatovymirni-masyvy-arraylist/ShoppingList.java) — перше знайомство з `ArrayList`: додавання, видалення, вставка на позицію. Челендж: додати перевірку — якщо товар вже є в списку, не додавати його вдруге (використовуючи `list.contains(...)`).

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: коли обрати звичайний масив, а коли `ArrayList`? Якщо кількість елементів наперед відома і не змінюється — масив; якщо елементи будуть додаватись/видалятись під час роботи програми — `ArrayList`.

## Домашнє завдання (необов'язково)
