# Основи CSS

**Блок:** Блок 6. Основи вебу та фінальний проєкт семестру
**Код заняття:** `060-veb-http-final-proekt/070-osnovy-css.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Стилізація, базовий layout.

## Мета заняття
- Вміти підключити CSS-файл до HTML-сторінки
- Знати основні властивості стилізації (кольори, шрифти, відступи, рамки)
- Вміти побудувати простий горизонтальний layout через `flexbox`

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Показати поруч [`index.html` без стилів](../060-osnovy-html/index.html) і [`index.html` зі стилями](src/070-osnovy-css/index.html) (та сама структура, реально перевірено в браузері — з CSS сторінка виглядає кардинально інакше). «Той самий HTML, зовсім інше враження — це і робить CSS».

### 2. Коротка теорія (15–20 хв)
**Підключення CSS до HTML:**
```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

**Синтаксис CSS-правила:**
```css
selector {
    property: value;
}
```
`selector` обирає, ДО ЯКИХ елементів застосувати стилі (тег `header`, клас `.myClass`, ідентифікатор `#myId`). `property: value;` — конкретна властивість (колір, розмір, відступ).

**Базові властивості:**
- `color` / `background-color` — колір тексту / фону.
- `font-family` / `font-size` — шрифт / розмір тексту.
- `margin` / `padding` — зовнішній / внутрішній відступ.
- `border` / `border-radius` — рамка / заокруглення кутів.
- `text-align` — вирівнювання тексту.

**Flexbox — базовий layout (розташування елементів):**
```css
nav ul {
    display: flex;      /* елементи в РЯДОК замість стовпця за замовчуванням */
    gap: 20px;           /* відстань між елементами */
    justify-content: center; /* вирівнювання по горизонталі */
}
```
`display: flex` — одна з найкорисніших властивостей CSS для базового розташування елементів у рядок чи стовпець з рівномірними відступами, без складних обчислень пікселів вручну.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`style.css`](src/070-osnovy-css/style.css) повністю разом із [`index.html`](src/070-osnovy-css/index.html), до якого він підключений: стилізація `header` (колір фону, заокруглення), `nav ul` (перетворення вертикального списку на горизонтальне меню через flexbox), `main`/`section` (картки з тінню відступів).

### 4. Керована практика (20–30 хв)
Разом змінити кольорову схему сторінки (`background-color` заголовку, колір посилань) — показати, як швидко змінюється весь вигляд сторінки через кілька значень у CSS, без торкання HTML.

### 5. Самостійна практика / челендж (20–30 хв)
Кожен студент підключає CSS до власної сторінки-профілю (заняття 060) і стилізує її на власний смак, використовуючи властивості з теорії. Челендж: додати `hover`-ефект на посилання чи кнопки (`a:hover { ... }` — стиль, що застосовується лише при наведенні миші).

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: HTML і CSS — величезні теми самі по собі (frontend-розробка як окремий напрямок, згадувалось ще на занятті 1 семестру), і сьогоднішній рівень — лише перше знайомство. Поглиблена frontend-розробка (React, сучасні фреймворки) — поза межами цього курсу, орієнтованого на backend, але базове розуміння корисне для будь-якого розробника.

## Домашнє завдання (необов'язково)
Дописати ще кілька стилів до власної сторінки-профілю: змінити шрифт (`font-family`), додати тінь блокам (`box-shadow`).
