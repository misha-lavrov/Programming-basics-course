# Підготовка фінального проєкту

**Блок:** Блок 6. Основи вебу та фінальний проєкт семестру
**Код заняття:** `060-veb-http-final-proekt/080-pidgotovka-finalnogo-proektu.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Вибір теми, технічне завдання, розподіл ролей (якщо в командах).

## Мета заняття
- Обрати тему фінального проєкту семестру
- Скласти письмове технічне завдання (класи, таблиці БД, меню)
- За потреби розподілити ролі в команді

## Структура заняття

### 1. Хук / мотивація (5 хв)
«Це заняття не про новий синтаксис — це про останній проєкт семестру, який об'єднає геть усе: Java, ООП, колекції, винятки, Git, SQL, і трохи HTTP/HTML. Побудуємо план перед тим, як почати писати код».

### 2. Теорія
Відсутня — це повністю організаційне, проєктне заняття.

### 3. Інструктаж (15–20 хв)
Розглянути разом [`project-ideas.md`](src/080-pidgotovka-finalnogo-proektu/project-ideas.md) — 5 ідей проєктів з обов'язковими критеріями:
- Мінімум 2 власні класи, що взаємодіють.
- Дані в реальній базі даних через JDBC.
- Усі 4 CRUD-операції.
- Обробка винятків.
- Консольне меню в циклі.
- Проєкт на GitHub з `.gitignore` і `README.md`.

Обговорити формат роботи: індивідуально чи в парах (як команда з блоку 4).

### 4. Керована практика (20–30 хв)
Кожен студент (або пара) обирає тему з переліку (чи узгоджує власну ідею з викладачем) і заповнює шаблон технічного завдання з [`project-ideas.md`](src/080-pidgotovka-finalnogo-proektu/project-ideas.md): назва проєкту, класи-сутності та їхні поля, таблиці бази даних, список операцій меню.

### 5. Самостійна практика / челендж (20–30 хв)
На основі заповненого технічного завдання: намалювати схему таблиць бази даних (за зразком заняття 020 блоку 5) і написати `CREATE TABLE` для неї. Для команд — розподілити, хто за яку частину функціоналу відповідає (за зразком розподілу ролей у командному проєкті блоку 4).

### 6. Рефлексія та підсумок (5–10 хв)
Кожен коротко (пів хвилини) озвучує групі обрану тему — щоб усі знали, над чим працюють одногрупники, і могли підказати одне одному на наступному занятті.

## Домашнє завдання (необов'язково)
Створити репозиторій на GitHub для фінального проєкту, зробити перший коміт зі схемою бази даних (`schema.sql`) і файлом технічного завдання.
