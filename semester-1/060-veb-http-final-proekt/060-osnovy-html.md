# Основи HTML

**Блок:** Блок 6. Основи вебу та фінальний проєкт семестру
**Код заняття:** `060-veb-http-final-proekt/060-osnovy-html.md`
**Тривалість:** 1.5–2 год
**Статус:** 🟢 розписано детально

## Опис
Структура сторінки, теги, семантика.

## Мета заняття
- Знати базову структуру HTML-документа
- Знати основні семантичні теги й коли який використовувати
- Вміти створити просту, структуровану HTML-сторінку

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
Нагадати заняття 010: у Network-панелі браузера бачили HTML як частину відповіді сервера. Запустити [`index.html`](src/060-osnovy-html/index.html) — відкрити подвійним кліком у браузері — показати готовий результат: «Сьогодні навчимось будувати саме такі сторінки».

### 2. Коротка теорія (15–20 хв)
**Базова структура HTML-документа:**
```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Заголовок вкладки браузера</title>
</head>
<body>
    <!-- Весь видимий вміст сторінки -->
</body>
</html>
```
`<!DOCTYPE html>` — каже браузеру, що це сучасний HTML5-документ. `lang="uk"` — мова сторінки (допомагає, наприклад, скрінрідерам для людей з порушеннями зору). `<meta charset="UTF-8">` — кодування тексту (без цього кирилиця могла б показуватись "кракозябрами" — та сама проблема кодування, що вже зустрічалась з Java на Windows).

**Семантичні теги — називають ЗМІСТ блоку, а не лише його вигляд:**
- `<header>` — шапка сторінки.
- `<nav>` — навігаційне меню.
- `<main>` — основний унікальний вміст сторінки.
- `<section>` — тематичний розділ усередині сторінки.
- `<footer>` — підвал сторінки.
- `<h1>`-`<h6>` — заголовки різного рівня важливості (лише один `<h1>` на сторінку — головний заголовок).
- `<p>` — параграф тексту.
- `<a href="...">` — посилання.
- `<ul>`/`<ol>` + `<li>` — ненумерований/нумерований список.

**Чому "семантичний" HTML кращий за суцільні `<div>`.** Семантичні теги одразу повідомляють, ЩО означає блок — і пошуковим системам (кращий SEO), і людям, що читають код, і допоміжним технологіям для людей з інвалідністю. `<div>` теж можна використовувати, коли жоден семантичний тег не підходить, але не варто ним замінювати ВСЕ.

### 3. Демонстрація / live-coding (15–20 хв)
Розібрати [`index.html`](src/060-osnovy-html/index.html) рядок за рядком: структура `header`/`nav`/`main` (із трьома `section`)/`footer`, посилання `<a href="mailto:...">` для email, атрибут `target="_blank"` (відкрити посилання в новій вкладці).

### 4. Керована практика (20–30 хв)
Разом додати до сторінки нову секцію — наприклад, "Улюблені технології" зі списком `<ul>`.

### 5. Самостійна практика / челендж (20–30 хв)
Кожен студент створює власну версію такої сторінки-профілю (копіює [`index.html`](src/060-osnovy-html/index.html) як шаблон і заповнює власними даними: ім'я, про себе, навички, контакти). Челендж: додати таблицю `<table>` з оцінками за семестр (стовпці: предмет, оцінка) — новий тег, не використаний у прикладі, варто самостійно знайти синтаксис (`<table>`, `<tr>`, `<th>`, `<td>`).

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити: сторінка поки виглядає "голо" — без кольорів, шрифтів, розташування. Анонсувати наступне заняття — CSS, який перетворить структуру на візуально привабливу сторінку.

## Домашнє завдання (необов'язково)
Додати до своєї сторінки-профілю ще одну секцію на вибір (наприклад "Плани на семестр 2").
