Готовий набір запитів для практики в Postman - усі перевірені, безпечний
публічний тестовий API (дані не зберігаються насправді, можна експериментувати
без ризику).

1. GET https://jsonplaceholder.typicode.com/users
   Очікувано: статус 200, масив з 10 користувачів.

2. GET https://jsonplaceholder.typicode.com/users/1
   Очікувано: статус 200, один об'єкт користувача.

3. GET https://jsonplaceholder.typicode.com/users/9999
   Очікувано: статус 404 (такого користувача не існує).

4. POST https://jsonplaceholder.typicode.com/posts
   Body -> raw -> JSON:
   {
     "title": "Мій перший пост",
     "body": "Текст посту",
     "userId": 1
   }
   Очікувано: статус 201 Created, у відповіді - ті самі дані + новий "id": 101.

5. PUT https://jsonplaceholder.typicode.com/posts/1
   Body -> raw -> JSON:
   {
     "id": 1,
     "title": "Оновлений заголовок",
     "body": "Оновлений текст",
     "userId": 1
   }
   Очікувано: статус 200, повністю замінений об'єкт (PUT замінює ВЕСЬ ресурс).

6. DELETE https://jsonplaceholder.typicode.com/posts/1
   Очікувано: статус 200, порожній об'єкт {} у відповіді.

Кроки для кожного запиту в Postman:
1. Натиснути "+" для нової вкладки запиту.
2. Обрати метод (GET/POST/PUT/DELETE) у випадаючому списку зліва від поля адреси.
3. Вставити URL.
4. Для POST/PUT: вкладка "Body" -> "raw" -> обрати тип "JSON" праворуч -> вставити текст.
5. Натиснути "Send".
6. Подивитись статус-код і час відповіді праворуч вгорі результату, і саму
   відповідь (JSON) - нижче.

Порада для заняття: зберегти всі запити в одну Collection (кнопка "Save"
при створенні запиту) - зручно повертатись і показувати групі.
