# Встановлення СУБД

**Блок:** Блок 5. Основи баз даних
**Код заняття:** `050-bazy-danyh/030-vstanovlennia-subd.md`
**Тривалість:** 1.5–2 год (закладайте буфер — встановлення СУБД зазвичай іде довше за встановлення звичайної програми)
**Статус:** 🟢 розписано детально

## Опис
PostgreSQL/MySQL + клієнт (наприклад DBeaver).

## Мета заняття
- Встановити PostgreSQL на свій комп'ютер
- Встановити DBeaver — універсальний графічний клієнт для роботи з базами даних
- Створити свою першу базу даних і підключитись до неї через DBeaver

## Підготовка викладача (перед заняттям)
- **Обов'язково розіслати цю інструкцію студентам за кілька днів до заняття** — встановлення СУБД технічно складніше за встановлення звичайного ПЗ (потрібно запам'ятати пароль адміністратора бази даних, встановленого під час інсталяції). На занятті — переважно перевірка й допомога.
- Мати інсталятори PostgreSQL і DBeaver на флешці на випадок повільного інтернету.

## Структура заняття

### 1. Хук / мотивація (5–10 хв)
«Сьогодні у вас з'явиться справжня, робоча база даних на власному комп'ютері — той самий інструмент, яким користуються професійні команди для зберігання мільйонів записів».

### 2. Коротка теорія (15–20 хв)
**Чому PostgreSQL.** Безкоштовна, з відкритим кодом, дуже потужна реляційна СУБД, одна з найпопулярніших у світі для backend-розробки (поряд з MySQL). Українською часто просто "Постгрес". Вибір саме PostgreSQL, а не MySQL, для цього курсу — обидві мови запитів (SQL) практично ідентичні на базовому рівні, який вивчатиметься; відмінності стають помітними лише на просунутих темах поза межами цього курсу.

**Клієнт бази даних (DBeaver).** Сам PostgreSQL не має власного зручного графічного інтерфейсу — це "сервер", що працює у фоновому режимі й чекає на запити. DBeaver — універсальна графічна програма для ПІДКЛЮЧЕННЯ до баз даних (PostgreSQL, MySQL та багатьох інших), перегляду таблиць, написання й виконання SQL-запитів у зручному вигляді.

### 3. Демонстрація / встановлення (основна частина заняття)

#### Крок 1. Встановлення PostgreSQL (Windows)
1. Перейти на [postgresql.org/download/windows](https://www.postgresql.org/download/windows/).
2. Натиснути "Download the installer" (веде на сайт EDB — офіційний партнер, що готує встановлювач для Windows).
3. Обрати останню стабільну версію для Windows x86-64, завантажити.
4. Запустити завантажений `.exe`-інсталятор.
5. Натискати "Next" на кроках вибору теки встановлення й компонентів (залишити все за замовчуванням: PostgreSQL Server, pgAdmin 4, Command Line Tools).
6. **Важливий крок:** інсталятор попросить придумати пароль для користувача-адміністратора бази даних (`postgres`). **Записати цей пароль** — він знадобиться щоразу при підключенні.
7. Залишити порт за замовчуванням — `5432`.
8. Залишити локаль за замовчуванням.
9. Дочекатись завершення встановлення. pgAdmin 4 (власний графічний інструмент PostgreSQL) можна закрити — далі користуватимемось DBeaver, зручнішим для наших потреб.

#### Крок 2. Встановлення DBeaver (Community Edition — безкоштовна)
1. Перейти на [dbeaver.io/download](https://dbeaver.io/download/).
2. Завантажити інсталятор для Windows (Community Edition — саме вона потрібна, не платна версія).
3. Запустити `.exe`-інсталятор, залишити всі опції за замовчуванням.
4. Дочекатись завершення встановлення, запустити DBeaver.

#### Крок 3. Підключення до PostgreSQL через DBeaver
1. У DBeaver: "Database" → "New Database Connection" (або кнопка з іконкою вилки/розетки на панелі інструментів).
2. Обрати "PostgreSQL" зі списку, натиснути "Next".
3. Заповнити поля: Host — `localhost`, Port — `5432`, Database — `postgres` (стандартна база, що завжди існує), Username — `postgres`, Password — той самий пароль, що придумали на кроці 1.
4. Натиснути "Test Connection" — якщо DBeaver попросить довантажити драйвер PostgreSQL при першому підключенні, погодитись ("Download").
5. Побачити повідомлення про успішне з'єднання, натиснути "Finish".

#### Крок 4. Створення власної бази даних для курсу
1. У дереві підключень (ліва панель) розкрити щойно створене з'єднання → "Databases".
2. Клацнути правою кнопкою на "Databases" → "Create New Database".
3. Назвати `college_db`, підтвердити.
4. Відкрити SQL-редактор для нової бази: клацнути на `college_db` → SQL Editor → "Open SQL script" (або комбінація клавіш, яку підкаже інтерфейс).

### 4. Керована практика (20–30 хв)
Кожен студент встановлює PostgreSQL і DBeaver, підключається, створює базу `college_db` за кроками вище. Викладач і ті, хто вже впорався, допомагають іншим — це найтехнічніше заняття курсу, труднощі варто сприймати спокійно.

### 5. Самостійна практика / челендж (20–30 хв)
У SQL-редакторі DBeaver для бази `college_db` виконати [`schema.sql`](src/020-reliatsiina-model/schema.sql), а потім [`seed-data.sql`](src/020-reliatsiina-model/seed-data.sql) із заняття 020 (виконати кожен файл повністю — в DBeaver зазвичай комбінація Alt+X або кнопка "Execute SQL Script"). Перевірити результат: розкрити `college_db` → "Tables" → подивитись вміст таблиці `students` (подвійний клік на таблиці).

### 6. Рефлексія та підсумок (5–10 хв)
Обговорити, з якими труднощами зіткнулись при встановленні. Наголосити: тепер є повноцінна база даних, готова для всіх наступних занять блоку.
