# Матеріали до занять блоку 5

## Спільна навчальна база даних

Одна база даних супроводжує весь блок — облік оцінок студентів. Схема й тестові
дані створюються один раз на занятті 020 і використовуються (з невеликими
доповненнями) до самого чекпоінту:

- [`020-reliatsiina-model/schema.sql`](020-reliatsiina-model/schema.sql) — 4 таблиці: `groups`, `students`, `subjects`, `grades`
- [`020-reliatsiina-model/seed-data.sql`](020-reliatsiina-model/seed-data.sql) — тестові дані (виконати ПІСЛЯ schema.sql)

Синтаксис — PostgreSQL (`SERIAL` для автоінкременту первинного ключа), відповідно
до заняття 030, де встановлюється саме PostgreSQL.

## Як виконати SQL-приклади

**У DBeaver (рекомендовано для занять):** відкрити SQL-редактор для потрібної
бази даних, вставити запит з відповідного `queries.sql`, виконати (Ctrl+Enter —
виконати запит під курсором, Alt+X — виконати весь скрипт).

**У терміналі psql:** `psql -U postgres -d college_db -f schema.sql`

## Про перевірку прикладів (важливо і чесно)

Усі SQL-запити в цьому блоці реально виконані й перевірені — але не на
PostgreSQL, а на SQLite (є в кожній системі "з коробки", не потребує
встановлення сервера). Базовий синтаксис `SELECT`/`WHERE`/`ORDER BY`/`JOIN`/
`GROUP BY`/`HAVING`, який тут використовується, ідентичний між SQLite та
PostgreSQL — тому результати можна вважати надійними. Синтаксис `CREATE TABLE`
у `schema.sql` — саме PostgreSQL (`SERIAL`), для перевірки використовувався
адаптований варіант (`INTEGER PRIMARY KEY AUTOINCREMENT`).

**Приклади JDBC (`090-java-jdbc/`, `100-praktychnyi-chekpoint-5/`)** перевірені
на компільованість (весь використаний API — `java.sql.*` — частина стандартного
JDK, для компіляції зовнішній драйвер не потрібен) і на коректну поведінку БЕЗ
підключення до бази (обробка помилок працює саме так, як описано в заняттях).
Реальне підключення до PostgreSQL в цьому середовищі протестувати не вдалося
(немає запущеного сервера бази даних) — перед першим реальним запуском варто
переконатись, що PostgreSQL встановлено й запущено (заняття 030), база
`college_db` створена зі схемою й даними, а драйвер PostgreSQL підключено
до проєкту.

## Примітка про іменування

Коментарі в SQL і Java — українською; назви таблиць, стовпців, класів і
змінних — англійською, як прийнято в індустрії. Файли з поміткою "приклад
розв'язку для викладача" призначені лише для викладача.
